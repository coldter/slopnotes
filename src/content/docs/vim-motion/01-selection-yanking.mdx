In Zed's vim mode, copying a word the old way means double-click to select, then `Cmd+C`. Vim flips the order: say the verb first, then name what to copy. No highlighting step.

```text
y  i  w
│  │  └─ noun:  "word"
│  └──── modifier: "inner"
└─────── verb: yank (copy)
```

`yiw` = "yank inner word." Cursor anywhere on a word, press those three keys, the word is in your clipboard. You never selected it — you described it.

## The targets you'll actually use

The pattern is `y` + a target: an **object** (`i` = inner / `a` = around) or a **motion** (`t`, `f`, `$`).

| Copy this | Press | Read it as |
|-----------|-------|------------|
| The word under the cursor | `yiw` | yank inner word |
| The word *plus* its trailing space | `yaw` | yank a word |
| Text inside `"…"` | `yi"` | yank inside quotes |
| Text inside `(…)` / `{…}` / `[…]` | `yi(` `yi{` `yi[` | yank inside brackets |
| Text inside an HTML/JSX tag | `yit` | yank inside tag |
| The whole current line | `yy` | yank line |
| Three lines, starting here | `3yy` | yank 3 lines |
| From cursor to end of line | `y$` | yank to line end |
| Up to (not incl.) the next `;` | `yt;` | yank till `;` |
| Up to *and including* the next `;` | `yf;` | yank find `;` |

Two distinctions to burn in early:

- **`i` vs `a`** — `i` is inner (contents only), `a` is around (contents plus whitespace/delimiters). `yiw` grabs `word`; `yaw` grabs `word ` with its space.
- **`t` vs `f`** — `t` stops *till* the character (exclusive), `f` *finds* it and includes it. `yt;` leaves the `;`; `yf;` takes it.

:::tip[Zed's vim mode and the system clipboard]
In Zed, a yank lands in Vim's own registers; whether it also reaches the OS clipboard is a setting. In `settings.json`:

```jsonc
{
  "vim": {
    // "never" | "on_yank" | "always"
    "use_system_clipboard": "on_yank"
  }
}
```

- `"never"` — yanks stay inside Vim; `Cmd+C`/`Cmd+V` are separate.
- `"on_yank"` — **recommended.** Every `y` also copies to the system clipboard.
- `"always"` — even deletes feed the clipboard (noisy; small motions clobber it).

Force the system clipboard per-yank with the register prefix `"+`: `"+yiw`, `"+yy`. Stash a copy in a named register with `"ayiw` (yank into register `a`), paste back with `"ap`.
:::

## When to drop to visual mode

Text objects don't cover everything — an irregular span only you can see. Highlight by hand, then yank.

| Key | Selects | Then |
|-----|---------|------|
| `v` | character-wise (grow with motions) | `y` to yank |
| `V` | whole lines | `y` to yank |
| `Ctrl-v` | a rectangular block (column) | `y` to yank |

:::caution[The trap]
If you press `v` and carefully extend over a whole word, line, or bracket pair — stop. That's a text object you're hand-drawing. `yiw`, `yy`, `yi(` already name it. Reach for visual mode only when the target is too irregular to name.
:::

## A quick drill

Run these in the playground (press `Esc` first). The goal: replace the select-it reflex with name-it.

<Steps>

1. Cursor on `greeting`. `yiw`, then move to a blank spot and `p` to paste. You copied a word without touching the boundary.

2. Cursor inside the `"…"` string. `yi"`, then `p`. You got the contents, no quotes.

3. Cursor inside `(a, b)`. `yi(`. The `reg "` chip now reads `a, b`.

4. On the `return` line, `yy` (the chip shows an `LW` badge — linewise). Then `3yy` from the `function` line to grab the whole body.

5. Fallback: `V` on the first line, then `y`. Same result as `yy` — which is the point. When a text object fits, prefer it; save visual mode for spans that don't.

</Steps>

## Recap

> Don't select-then-copy. Say **copy** (`y`), then **name what to copy** (`iw`, `i"`, `i(`, `yy`) — and drop to visual mode only when the target is too irregular to name.

The grammar generalizes: swap `y` for `d` to delete the same targets, `c` to change them. Same nouns, new verb.
