Ktor is a toolkit, not a framework — you pick the pieces you need. Built by JetBrains, coroutine-first, DSL-driven. Feels like Express.js or Echo/Chi. We rebuild the same task API from Module 08 for a direct comparison.

## Mental model

| Concept | Express.js (TS) | Go (Echo/Chi) | Spring Boot | Ktor |
|---|---|---|---|---|
| Philosophy | middleware-based | stdlib + router | batteries-included | plugin-based |
| Routing | `app.get("/path", handler)` | `e.GET("/path", handler)` | `@GetMapping("/path")` | `get("/path") { }` DSL |
| Middleware | `app.use(fn)` | `e.Use(fn)` | Filters | `install(Plugin)` |
| DI | tsyringe / manual | wire / manual | Built-in IoC | Koin / manual |
| JSON | built-in | `encoding/json` | Jackson (auto) | kotlinx.serialization |
| Config | dotenv | envconfig | application.yml | application.conf (HOCON) |
| Testing | supertest | httptest | MockMvc | `testApplication { }` |
| Startup | ~100ms | ~10ms | ~1-3s | ~100-300ms |
| Memory | ~30-80MB | ~10-30MB | ~100-300MB | ~30-80MB |

:::tip[The trade-off]
Ktor gives you less out of the box — no built-in ORM, no Actuator, no auto-configured pooling. You assemble from individual libraries. Great for control and small footprint; more manual wiring for complex enterprise apps.
:::

|---|---|---|
| `kotlin("plugin.spring")` | `kotlin("plugin.serialization")` | Spring needs open classes; Ktor needs serialization codegen |
| `org.springframework.boot` plugin | `io.ktor.plugin` | Framework-specific plugins |
| `spring-boot-starter-web` (one dep) | multiple `ktor-server-*` deps | Ktor: pick individual features |
| `jackson-module-kotlin` | `ktor-serialization-kotlinx-json` | Different JSON libraries |
| `kotlin-reflect` (required) | not needed | Ktor avoids reflection |

## Routing

Ktor uses a Kotlin DSL — `get("/path") { }` blocks wired into `routing { }`.

```kotlin title="src/main/kotlin/com/example/taskapi/routes/HelloRoutes.kt"
fun Route.helloRoutes() {
    get("/hello") {
        call.respondText("Hello, World!")
    }
    get("/hello/json") {
        call.respond(mapOf("message" to "Hello, World!"))
    }
}
```

```kotlin title="src/main/kotlin/com/example/taskapi/Application.kt"
fun Application.configureRouting() {
    routing {
        helloRoutes()
    }
}
```

### Route nesting

```kotlin
fun Route.taskRoutes() {
    route("/api/tasks") {
        get { /* GET /api/tasks */ }
        get("/{id}") { /* GET /api/tasks/{id} */ }
        post { /* POST /api/tasks */ }
        put("/{id}") { }
        delete("/{id}") { }
        route("/status") {
            get("/{status}") { }
        }
        get("/search") { }
    }
}
```

### Full CRUD route file

```kotlin title="src/main/kotlin/com/example/taskapi/routes/TaskRoutes.kt"
fun Route.taskRoutes() {
    val repository by inject<TaskRepository>()

    route("/api/tasks") {

        get {
            call.respond(repository.findAll().map { it.toResponse() })
        }

        // NOTE: /search must be defined BEFORE /{id} or "search" matches as an id
        get("/search") {
            val query = call.request.queryParameters["q"]
                ?: return@get call.respond(HttpStatusCode.BadRequest, mapOf("error" to "Missing 'q'"))
            call.respond(repository.search(query).map { it.toResponse() })
        }

        get("/{id}") {
            val id = call.parameters["id"]!!
            val task = repository.findById(id)
                ?: return@get call.respond(
                    HttpStatusCode.NotFound,
                    mapOf("error" to "Not Found", "message" to "Task not found: $id")
                )
            call.respond(task.toResponse())
        }

        post {
            val request = call.receive<CreateTaskRequest>()
            val task = Task(
                title = request.title,
                description = request.description,
                priority = Priority.valueOf(request.priority)
            )
            val saved = repository.save(task)
            call.response.header("Location", "/api/tasks/${saved.id}")
            call.respond(HttpStatusCode.Created, saved.toResponse())
        }

        put("/{id}") {
            val id = call.parameters["id"]!!
            val existing = repository.findById(id)
                ?: return@put call.respond(
                    HttpStatusCode.NotFound,
                    mapOf("error" to "Not Found", "message" to "Task not found: $id")
                )
            val request = call.receive<UpdateTaskRequest>()
            val updated = existing.copy(
                title = request.title ?: existing.title,
                description = request.description ?: existing.description,
                status = request.status?.let { TaskStatus.valueOf(it.uppercase()) } ?: existing.status,
                priority = request.priority?.let { Priority.valueOf(it.uppercase()) } ?: existing.priority,
                updatedAt = Instant.now()
            )
            call.respond(repository.save(updated).toResponse())
        }

        delete("/{id}") {
            val id = call.parameters["id"]!!
            if (!repository.deleteById(id)) {
                return@delete call.respond(
                    HttpStatusCode.NotFound,
                    mapOf("error" to "Not Found", "message" to "Task not found: $id")
                )
            }
            call.respond(HttpStatusCode.NoContent)
        }
    }
}
```

Every route handler is a `suspend` lambda — Ktor runs them on coroutine dispatchers, never blocking a thread.

## Plugins (middleware)

In Ktor, middleware = **plugins** installed with `install(Plugin) { }` — identical concept to `app.use()` in Express.

<Mermaid title="Ktor request pipeline" code={`
flowchart LR
  REQ["HTTP Request"] --> CL["CallLogging"]
  CL --> CN["ContentNegotiation"]
  CN --> CORS["CORS"]
  CORS --> SP["StatusPages"]
  SP --> H["Route handler (suspend)"]
  H --> RESP["HTTP Response"]
`} height={360} />

```kotlin
fun Application.module() {
    install(ContentNegotiation) { json() }    // ≈ app.use(express.json())
    install(StatusPages) { /* error handlers */ }  // ≈ app.use(errorHandler)
    install(CallLogging) { level = Level.INFO }    // ≈ app.use(morgan("dev"))
    install(CORS) { /* config */ }
}
```

### ContentNegotiation with kotlinx.serialization

```kotlin title="src/main/kotlin/com/example/taskapi/plugins/Serialization.kt"
fun Application.configureSerialization() {
    install(ContentNegotiation) {
        json(Json {
            prettyPrint = true
            isLenient = false
            ignoreUnknownKeys = true
            encodeDefaults = true
        })
    }
}
```

After installing, `call.respond(myObject)` auto-serializes to JSON and `call.receive<MyType>()` auto-deserializes.

### StatusPages for error handling

Ktor's equivalent of Spring's `@RestControllerAdvice`:

```kotlin title="src/main/kotlin/com/example/taskapi/plugins/ErrorHandling.kt"
@Serializable
data class ErrorResponse(val status: Int, val error: String, val message: String)

fun Application.configureErrorHandling() {
    install(StatusPages) {
        exception<TaskNotFoundException> { call, cause ->
            call.respond(HttpStatusCode.NotFound,
                ErrorResponse(404, "Not Found", cause.message ?: "Resource not found"))
        }
        exception<IllegalArgumentException> { call, cause ->
            call.respond(HttpStatusCode.BadRequest,
                ErrorResponse(400, "Bad Request", cause.message ?: "Invalid request"))
        }
        exception<Throwable> { call, cause ->
            call.application.environment.log.error("Unhandled exception", cause)
            call.respond(HttpStatusCode.InternalServerError,
                ErrorResponse(500, "Internal Server Error", "An unexpected error occurred"))
        }
        status(HttpStatusCode.NotFound) { call, status ->
            call.respond(status, ErrorResponse(404, "Not Found", "Resource not found"))
        }
    }
}

class TaskNotFoundException(val taskId: String) : RuntimeException("Task not found: $taskId")
```

### CORS and CallLogging

```kotlin
fun Application.configureCORS() {
    install(CORS) {
        allowHost("localhost:3000")
        allowHost("myapp.com", schemes = listOf("https"))
        allowMethod(HttpMethod.Put)
        allowMethod(HttpMethod.Delete)
        allowHeader(HttpHeaders.ContentType)
        allowHeader(HttpHeaders.Authorization)
        allowCredentials = true
        maxAgeInSeconds = 3600
    }
}

fun Application.configureCallLogging() {
    install(CallLogging) {
        level = org.slf4j.event.Level.INFO
        filter { call -> call.request.path().startsWith("/api") }
        format { call ->
            "${call.request.httpMethod.value} ${call.request.path()} -> ${call.response.status()}"
        }
    }
}
```

### Custom plugins

```kotlin
val ResponseTimingPlugin = createApplicationPlugin(name = "ResponseTiming") {
    onCall { call ->
        call.attributes.put(startTimeKey, System.currentTimeMillis())
    }
    onCallRespond { call, _ ->
        val start = call.attributes.getOrNull(startTimeKey) ?: return@onCallRespond
        call.response.header("X-Response-Time", "${System.currentTimeMillis() - start}ms")
    }
}

private val startTimeKey = AttributeKey<Long>("startTime")

fun Application.configureCustomPlugins() {
    install(ResponseTimingPlugin)
}
```

## Request/response handling

```kotlin
// Receive body (uses ContentNegotiation)
val request = call.receive<CreateTaskRequest>()

// Respond
call.respond(taskResponse)                              // 200 + JSON
call.respond(HttpStatusCode.Created, taskResponse)      // 201 + JSON
call.respondText("Hello")                               // 200 + text/plain
call.respond(HttpStatusCode.NoContent)                  // 204

// Headers
val authHeader = call.request.headers["Authorization"]
call.response.header("Location", "/api/tasks/${task.id}")
```

| Framework | Receive body | Respond |
|---|---|---|
| Ktor | `call.receive<T>()` | `call.respond(...)` / `call.respondText(...)` |
| Express | `req.body` (with `express.json()`) | `res.json(...)` / `res.send(...)` |
| Echo | `c.Bind(&req)` | `c.JSON(...)` |
| Spring Boot | `@RequestBody request: T` | return value / `ResponseEntity` |

## Serialization

Ktor uses **kotlinx.serialization** — compile-time codegen, no reflection. The `kotlin("plugin.serialization")` Gradle plugin generates the code.

```kotlin title="src/main/kotlin/com/example/taskapi/models/Task.kt"
@Serializable
data class Task(
    val id: String = UUID.randomUUID().toString(),
    val title: String,
    val description: String = "",
    val status: TaskStatus = TaskStatus.TODO,
    val priority: Priority = Priority.MEDIUM,
    val createdAt: String = java.time.Instant.now().toString(),
    val updatedAt: String = java.time.Instant.now().toString()
)

@Serializable
enum class TaskStatus { TODO, IN_PROGRESS, DONE }

@Serializable
enum class Priority { LOW, MEDIUM, HIGH, CRITICAL }

@Serializable
data class CreateTaskRequest(
    val title: String,
    val description: String = "",
    val priority: String = "MEDIUM"
)

@Serializable
data class UpdateTaskRequest(
    val title: String? = null,
    val description: String? = null,
    val status: String? = null,
    val priority: String? = null
)

fun Task.toResponse() = TaskResponse(
    id = id, title = title, description = description,
    status = status.name, priority = priority.name,
    createdAt = createdAt, updatedAt = updatedAt
)
```

| Feature | kotlinx.serialization | Jackson | encoding/json (Go) |
|---|---|---|---|
| Annotation | `@Serializable` | none (auto) or `@JsonProperty` | `json:"field"` tags |
| Codegen | compile time | runtime reflection | runtime reflection |
| Null handling | Kotlin nullability | `@JsonInclude(NON_NULL)` | `omitempty` |
| Default values | native | needs module | no direct equivalent |
| Custom field names | `@SerialName("x")` | `@JsonProperty("x")` | `json:"x"` |
| Ignore field | `@Transient` | `@JsonIgnore` | `json:"-"` |

Sealed classes serialize natively with a discriminator field:

```kotlin
@Serializable
sealed class NotificationEvent {
    @Serializable
    data class TaskCreated(val taskId: String, val title: String) : NotificationEvent()

    @Serializable
    data class TaskCompleted(val taskId: String, val completedBy: String) : NotificationEvent()
}
// Serializes as: {"type":"...TaskCreated","taskId":"abc","title":"My Task"}
```

## Dependency injection with Koin

Ktor has no built-in DI. Koin is the popular choice — DSL-based, Kotlin-first.

```kotlin title="src/main/kotlin/com/example/taskapi/di/AppModule.kt"
val appModule = module {
    // single = singleton for the app's lifetime
    single<TaskRepository> { InMemoryTaskRepository() }
}
```

```kotlin title="src/main/kotlin/com/example/taskapi/Application.kt"
fun Application.module() {
    install(Koin) {
        slf4jLogger()
        modules(appModule)
    }
    configureSerialization()
    configureErrorHandling()
    configureCallLogging()
    routing {
        taskRoutes()
    }
}
```

```kotlin
// Inject into route handlers with a property delegate
fun Route.taskRoutes() {
    val repository by inject<TaskRepository>()
    // ...
}
```

`single { }` = singleton; `factory { }` = new instance each time.

| Feature | Spring DI | Koin | Go (manual) | tsyringe |
|---|---|---|---|---|
| Annotation-based | Yes | No | No | Yes |
| DSL-based | No | Yes | No | No |
| Compile-time safety | No | No | Yes | No |
| Reflection | Heavy | Minimal | None | Heavy |
| Auto-discovery | Yes | No (explicit) | No | No |

## Request validation

Code-based (like Zod in TS), not annotation-based:

```kotlin title="src/main/kotlin/com/example/taskapi/plugins/Validation.kt"
fun Application.configureValidation() {
    install(RequestValidation) {
        validate<CreateTaskRequest> { request ->
            val errors = mutableListOf<String>()

            if (request.title.isBlank()) errors.add("Title is required and cannot be blank")
            if (request.title.length > 200) errors.add("Title must be at most 200 characters")
            if (request.description.length > 2000) errors.add("Description must be at most 2000 characters")
            if (request.priority !in listOf("LOW", "MEDIUM", "HIGH", "CRITICAL"))
                errors.add("Priority must be one of: LOW, MEDIUM, HIGH, CRITICAL")

            if (errors.isEmpty()) ValidationResult.Valid
            else ValidationResult.Invalid(errors)
        }
    }
}
```

Failed validation throws `RequestValidationException` — handle it in `StatusPages` for a 400.

## Authentication (JWT)

```kotlin title="src/main/kotlin/com/example/taskapi/plugins/Auth.kt"
fun Application.configureAuthentication() {
    val jwtSecret = environment.config.property("jwt.secret").getString()
    val jwtIssuer = environment.config.property("jwt.issuer").getString()
    val jwtAudience = environment.config.property("jwt.audience").getString()

    install(Authentication) {
        jwt("auth-jwt") {
            realm = "Task API"
            verifier(
                JWT.require(Algorithm.HMAC256(jwtSecret))
                    .withAudience(jwtAudience)
                    .withIssuer(jwtIssuer)
                    .build()
            )
            validate { credential ->
                if (credential.payload.audience.contains(jwtAudience)) JWTPrincipal(credential.payload)
                else null
            }
            challenge { _, _ ->
                call.respond(HttpStatusCode.Unauthorized,
                    ErrorResponse(401, "Unauthorized", "Invalid or missing token"))
            }
        }
    }
}
```

Protect routes by wrapping in `authenticate("auth-jwt") { }`; inside, `call.principal<JWTPrincipal>()` gives the verified token.

## Testing

`testApplication { }` starts the app in-process — no port binding, no `@SpringBootTest`, no `@Autowired`. Faster than Spring's MockMvc, similar to Go's httptest.

```kotlin title="src/test/kotlin/com/example/taskapi/TaskRoutesTest.kt"
class TaskRoutesTest {

    @Test
    fun `GET tasks should return empty list initially`() = testApplication {
        application { module() }

        val response = client.get("/api/tasks")
        assertEquals(HttpStatusCode.OK, response.status)
        assertEquals("[]", response.bodyAsText())
    }

    @Test
    fun `POST should create a task`() = testApplication {
        application { module() }

        val response = client.post("/api/tasks") {
            contentType(ContentType.Application.Json)
            setBody("""{"title": "Test task", "description": "Testing", "priority": "HIGH"}""")
        }

        assertEquals(HttpStatusCode.Created, response.status)
        assertTrue(response.bodyAsText().contains("Test task"))
    }

    @Test
    fun `GET should return 404 for nonexistent task`() = testApplication {
        application { module() }
        val response = client.get("/api/tasks/nonexistent-id")
        assertEquals(HttpStatusCode.NotFound, response.status)
    }
}
```

Typed clients and mock dependencies:

```kotlin
// Typed client with content negotiation
val jsonClient = createClient {
    install(io.ktor.client.plugins.contentnegotiation.ContentNegotiation) { json() }
}
val response = jsonClient.post("/api/tasks") {
    contentType(ContentType.Application.Json)
    setBody(CreateTaskRequest(title = "Typed test"))

// Override Koin modules to inject fakes
@Test

```

| Framework | Test setup overhead | Starts real server? | Speed |
|---|---|---|---|
| Ktor `testApplication` | one function call | No (in-process) | Very fast |
| Spring `@SpringBootTest` + MockMvc | annotations, context startup | No (mock servlet) | Slow (~2-5s) |
| supertest (Express) | import app | No (in-process) | Fast |
| Go httptest | create request + recorder | No (in-process) | Very fast |

## Ktor vs Spring Boot

| Metric | Spring Boot | Ktor |
|---|---|---|
| Startup time | 1-3s | 100-300ms |
| Memory (idle) | 100-300MB | 30-80MB |
| Requests/sec (simple JSON) | ~50-80K | ~60-100K |

| Area | Spring Boot | Ktor |
|---|---|---|
| ORM | Spring Data JPA | Exposed, Ktorm, raw JDBC |
| Security | Spring Security | Basic auth plugin + manual |
| Caching | Spring Cache | Manual (Redis client) |
| Monitoring | Actuator + Micrometer (built-in) | Manual (Micrometer plugin) |
| API docs | SpringDoc OpenAPI (mature) | Ktor OpenAPI plugin (newer) |
| Scheduling | `@Scheduled` (built-in) | coroutine-based (manual) |

**Choose Ktor** for lightweight microservices, serverless (fast startup), pure-Kotlin/KMP projects. **Choose Spring Boot** for enterprise, database-heavy apps (Spring Data JPA is unmatched), comprehensive monitoring.
