## Goal

Build a file-processing pipeline with Flow: read CSV line by line, parse, filter, transform, aggregate, write summary — with proper dispatcher usage and error handling.

## What you'll build

Six stages, each a Flow operator:

1. **Read** — CSV file line by line as `Flow<String>`, on `Dispatchers.IO`.
2. **Parse** — line → `Transaction`, skip malformed.
3. **Filter** — drop below minimum amount.
4. **Transform** — normalize (uppercase category, round amount).
5. **Aggregate** — group by category, compute totals/averages.
6. **Output** — write summary to file, on `Dispatchers.IO`.

```kotlin
data class Transaction(
    val id: String,
    val amount: Double,
    val category: String,
    val date: String,
    val description: String,
)

data class CategorySummary(
    val category: String,
    val count: Int,
    val totalAmount: Double,
    val averageAmount: Double,
)
```

### The read stage

`flow { }` emits one value at a time. `.flowOn(Dispatchers.IO)` moves the blocking file read onto the IO pool. `lineSequence()` is lazy and `emit` suspends until the collector is ready — a million-line file never materializes at once.

```kotlin title="src/main/kotlin/Main.kt" {1,8}
fun readCsvLines(file: File): Flow<String> = flow {
    file.bufferedReader().use { reader ->
        reader.lineSequence()
            .drop(1) // skip header
            .forEach { line -> emit(line) }
    }
}.flowOn(Dispatchers.IO)
```

### Parse, transform, aggregate

`parseLine` returns null for malformed lines — `mapNotNull` skips them. `normalize` uses `data class` `copy` (immutable transform). `aggregate` is plain collection math once the Flow is drained to a `List`.

```kotlin title="src/main/kotlin/Main.kt" {3,4}
fun parseLine(line: String): Transaction? {
    val parts = line.split(",", limit = 5)
    if (parts.size < 5) return null
    val amount = parts[1].trim().toDoubleOrNull() ?: return null
    return Transaction(
        id = parts[0].trim(),
        amount = amount,
        category = parts[2].trim(),
        date = parts[3].trim(),
        description = parts[4].trim(),
    )
}
```

```kotlin title="src/main/kotlin/Main.kt"
fun normalize(tx: Transaction): Transaction = tx.copy(
    category = tx.category.uppercase(),
    amount = Math.round(tx.amount * 100.0) / 100.0,
)
```

```kotlin title="src/main/kotlin/Main.kt" {2}
fun aggregate(transactions: List<Transaction>): List<CategorySummary> =
    transactions
        .groupBy { it.category }
        .map { (category, txns) ->
            CategorySummary(
                category = category,
                count = txns.size,
                totalAmount = Math.round(txns.sumOf { it.amount } * 100.0) / 100.0,
                averageAmount = Math.round(txns.sumOf { it.amount } / txns.size * 100.0) / 100.0,
            )
        }
        .sortedByDescending { it.totalAmount }
```

### The write stage

```kotlin title="src/main/kotlin/Main.kt" {1}
suspend fun writeSummary(file: File, summaries: List<CategorySummary>) = withContext(Dispatchers.IO) {
    file.bufferedWriter().use { writer ->
        writer.write("category,count,total,average")
        writer.newLine()
        for (summary in summaries) {
            writer.write("${summary.category},${summary.count},${summary.totalAmount},${summary.averageAmount}")
            writer.newLine()
        }
    }
}
```

### Wiring it together

```kotlin title="src/main/kotlin/Main.kt" {2,9-16,20}
fun main() = runBlocking {
    val inputFile = File("sample-transactions.csv")
    val outputFile = File("summary-output.csv")
    val minAmount = 50.0

    if (!inputFile.exists()) {
        println("Generating sample CSV with 1000 transactions...")
        generateSampleCsv(inputFile, 1000)
    }

    println("Processing ${inputFile.name}...")
    println("=".repeat(60))

    var parseErrors = 0
    var totalRead = 0
    var totalFiltered = 0

    val elapsed = measureTimeMillis {
        val transactions = readCsvLines(inputFile)
            .onEach { totalRead++ }
            .mapNotNull { line ->
                parseLine(line).also { if (it == null) parseErrors++ }
            }
            .filter { it.amount >= minAmount }
            .onEach { totalFiltered++ }
            .map { normalize(it) }
            .flowOn(Dispatchers.Default)
            .catch { e -> println("Pipeline error: ${e.message}") }
            .toList()

        val summaries = aggregate(transactions)

        println("\nCategory Summaries:")
        println("-".repeat(60))
        println("%-15s %6s %12s %12s".format("Category", "Count", "Total", "Average"))
        println("-".repeat(60))
        for (s in summaries) {
            println("%-15s %6d %12.2f %12.2f".format(s.category, s.count, s.totalAmount, s.averageAmount))
        }

        writeSummary(outputFile, summaries)
    }

    println("=".repeat(60))
    println("Lines read:     $totalRead")
    println("Parse errors:   $parseErrors")
    println("After filter:   $totalFiltered")
    println("Time:           ${elapsed}ms")
    println("Output written: ${outputFile.absolutePath}")
}
```

:::note[Why two `flowOn` calls?]
`flowOn` only affects stages *upstream* of it. The read stage caps itself with `.flowOn(Dispatchers.IO)`. The `.flowOn(Dispatchers.Default)` in `main` then governs parse/filter/transform. Each blocking step on IO, each CPU step on Default — that's the dispatcher discipline.
:::
