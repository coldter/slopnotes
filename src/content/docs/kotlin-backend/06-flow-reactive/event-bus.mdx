## Goal

Build a type-safe event bus on `SharedFlow` — the Node.js `EventEmitter` / Go channel fan-out, but type-safe: subscribers ask for events of type `T` and `filterIsInstance` guarantees that's all they get.

## What you'll build

One `EventBus` class backed by a single `MutableSharedFlow<Any>`:

1. `publish(event: Any)` — `suspend`, emits to all matching subscribers.
2. `subscribe<T>(filter: (T) -> Boolean = { true }): Flow<T>` — typed, optionally filtered view.
3. Configurable **replay count** so late subscribers see recent events.
4. Event types as sealed classes: `UserEvent`, `OrderEvent`, `SystemEvent`.

### The event types

Sealed classes = closed set of variants, exhaustive `when` in subscribers.

```kotlin title="src/main/kotlin/Main.kt"
import kotlinx.coroutines.*
import kotlinx.coroutines.flow.*

// --- Event types ---

sealed class UserEvent {
    data class LoggedIn(val userId: String, val timestamp: Long = System.currentTimeMillis()) : UserEvent()
    data class LoggedOut(val userId: String, val timestamp: Long = System.currentTimeMillis()) : UserEvent()
}

sealed class OrderEvent {
    data class Created(val orderId: String, val amount: Double) : OrderEvent()
    data class Shipped(val orderId: String, val trackingNumber: String) : OrderEvent()
}

data class SystemEvent(val type: String, val message: String)
```

### The EventBus

30 lines. Key points:

- Backing field is a single `MutableSharedFlow<Any>(replay = replay)`. `SharedFlow` is **hot** — emits whether or not anyone is listening. `replay` controls what new subscribers receive.
- `subscribe` is `inline` + `reified` so `filterIsInstance<T>()` can check the runtime type. `noinline` on the filter keeps it a real lambda.
- `subscribeAll()` returns the raw stream via `asSharedFlow()` — read-only.

```kotlin title="src/main/kotlin/Main.kt" {2,5,11,15-16}
// --- Event Bus ---

class EventBus(replay: Int = 0) {
    private val _events = MutableSharedFlow<Any>(replay = replay)

    suspend fun publish(event: Any) {
        _events.emit(event)
    }

    inline fun <reified T> subscribe(noinline filter: (T) -> Boolean = { true }): Flow<T> =
        _events
            .filterIsInstance<T>()
            .filter(filter)

    fun subscribeAll(): Flow<Any> = _events.asSharedFlow()

    val subscriberCount: Int
        get() = _events.subscriptionCount.value
}
```

:::note[Why `inline` + `reified` + `noinline`]
`filterIsInstance<T>()` needs the actual class of `T` at runtime, which a normal generic can't provide (JVM erases it). `inline fun <reified T>` copies the call site in and keeps `T`'s identity. Because the body inlines, the `filter` lambda would inline too — `noinline` keeps it a real lambda object.
:::

### The demo

Each subscriber is its own coroutine collecting a different slice. Subscriber 2 narrows to `OrderEvent.Created` *and* applies `{ it.amount > 100.0 }` — the $45 order is dropped for it but seen by all-orders and audit.

```kotlin title="src/main/kotlin/Main.kt" {1,2,9,16,42}
fun main() = runBlocking {
    val bus = EventBus(replay = 1)   // replay last event for late subscribers

    val userSub = launch {
        bus.subscribe<UserEvent>().collect { event ->
            when (event) {
                is UserEvent.LoggedIn -> println("[UserSub]  Login: ${event.userId}")
                is UserEvent.LoggedOut -> println("[UserSub]  Logout: ${event.userId}")
            }
        }
    }

    val orderSub = launch {
        bus.subscribe<OrderEvent.Created> { it.amount > 100.0 }.collect { event ->
            println("[OrderSub] High-value order: ${event.orderId} = \$${event.amount}")
        }
    }

    val allOrdersSub = launch {
        bus.subscribe<OrderEvent>().collect { event ->
            when (event) {
                is OrderEvent.Created -> println("[AllOrders] Created: ${event.orderId}")
                is OrderEvent.Shipped -> println("[AllOrders] Shipped: ${event.orderId} -> ${event.trackingNumber}")
            }
        }
    }

    val systemSub = launch {
        bus.subscribe<SystemEvent>().collect { event ->
            println("[System]   ${event.type}: ${event.message}")
        }
    }

    val auditLog = mutableListOf<String>()
    val auditSub = launch {
        bus.subscribeAll().collect { event ->
            auditLog.add("[${System.currentTimeMillis()}] $event")
        }
    }

    delay(100)   // give subscribers time to register

    println("=".repeat(60))
    println("Publishing events...")
    println("=".repeat(60))

    bus.publish(UserEvent.LoggedIn("alice"))
    delay(50)
    bus.publish(OrderEvent.Created("ORD-001", 250.0))
    delay(50)
    bus.publish(OrderEvent.Created("ORD-002", 45.0))    // below $100 filter
    delay(50)
    bus.publish(UserEvent.LoggedIn("bob"))
    delay(50)
    bus.publish(OrderEvent.Shipped("ORD-001", "TRACK-XYZ"))
    delay(50)
    bus.publish(SystemEvent("HEALTH", "All services nominal"))
    delay(50)
    bus.publish(UserEvent.LoggedOut("alice"))
    delay(50)

    delay(200)

    println("=".repeat(60))
    println("Audit Log (${auditLog.size} events):")
    auditLog.forEach { println("  $it") }

    userSub.cancel(); orderSub.cancel(); allOrdersSub.cancel(); systemSub.cancel(); auditSub.cancel()
    println("=".repeat(60))
    println("Event bus demo complete.")
}
```

:::caution[Subscribers must be running before you publish]
A `SharedFlow` only delivers to collectors that are *currently* collecting (plus replay buffer). There's no queue for future readers. That's why the demo `delay(100)`s before publishing.
:::

## Run it

```bash
./gradlew run
```

Each subscriber prints its slice — `OrderSub` ignores the $45 order; `AllOrders` and the audit log catch everything.

## Test it

```bash
./gradlew test
```

Turbine's `flow.test { }` lets you `awaitItem()` per emission and assert the bus delivers (and filters) exactly what you expect.
