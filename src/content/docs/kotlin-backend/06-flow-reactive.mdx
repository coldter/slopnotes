Flow is Kotlin's cold asynchronous stream with built-in backpressure — mapped from RxJS Observables and Go channel pipelines.

## Flow vs Channel

| Feature | Flow | Channel |
|---|---|---|
| Nature | Cold — nothing until collected | Hot — produces regardless of consumers |
| Consumers | Each collector gets its own stream | Multiple consumers share the stream |
| Use case | Data transformation pipeline | Coroutine-to-coroutine communication |
| Cancellation | Cancelling collector stops production | Must close channel explicitly |

**Rule:** Use `Flow` for data pipelines. Use `Channel` for coroutine communication.

## Flow basics

Cold streams — each `collect` runs the flow from scratch:

```kotlin
fun numbersFlow(): Flow<Int> = flow {
    println("Flow started")       // only runs when collected
    for (i in 1..3) {
        delay(100)
        emit(i)
    }
}

fun main() = runBlocking {
    val myFlow = numbersFlow()
    myFlow.collect { println("Got: $it") }       // runs the flow
    myFlow.collect { println("Again: $it") }     // runs it again
}
```

## Builders

```kotlin
flow { emit("Hello"); emit("World") }       // main builder
flowOf(1, 2, 3)                              // from fixed values
listOf(1, 2, 3).asFlow()                     // from collection
(1..10).asFlow()                             // from range

// channelFlow — concurrent emission from multiple coroutines
val concurrent = channelFlow {
    launch { send("from coroutine 1") }
    launch { delay(100); send("from coroutine 3") }
}

// callbackFlow — bridge callback-based APIs
fun fileWatcher(dir: String): Flow<String> = callbackFlow {
    val watcher = object : FileChangeListener {
        override fun onFileChanged(path: String) { trySend(path) }  // non-blocking
    }
    registerWatcher(dir, watcher)
    awaitClose { unregisterWatcher(dir, watcher) }   // cleanup on cancel
}
```

## Operators

Operators return new `Flow` instances — nothing executes until `collect`.

```kotlin
(1..5).asFlow()
    .map { it * it }              // 1, 4, 9, 16, 25
    .filter { it % 2 == 0 }       // keep evens
    .transform { value ->         // emit 0, 1, or N values per input
        emit("Processing $value")
        emit("Done with $value")
    }
    .take(5)                      // limit — cancels flow after 5
    .drop(3)                      // skip first 3
    .onEach { println("Side effect: $it") }   // like RxJS tap
    .collect { println(it) }

// Terminal operators
(1..10).asFlow().reduce { acc, v -> acc + v }    // 55
(1..5).asFlow().fold(1) { acc, v -> acc * v }    // 120
(1..5).asFlow().map { it * it }.toList()
flowOf(1, 2, 2, 3).toSet()
(1..10).asFlow().first { it % 2 == 0 }           // 2
flowOf(42).single()
```

## Combining flows

```kotlin
// zip — pair by position
flowOf("Alice", "Bob").zip(flowOf(30, 25)) { name, age -> "$name is $age" }

// combine — latest from each whenever either emits
flow1.combine(flow2) { a, b -> "$a + $b" }

// merge — interleave all values in arrival order
merge(flow1, flow2)
```

| Operation | RxJS | Go | Kotlin Flow |
|---|---|---|---|
| Pair by position | `zip()` | manual sync | `zip()` |
| Latest from each | `combineLatest()` | manual | `combine()` |
| Merge all | `merge()` | fan-in | `merge()` |

## FlatMap operators

| Operator | Behavior | Use case | RxJS |
|---|---|---|---|
| `flatMapConcat` | Sequential, in order | Ordered API calls | `concatMap` |
| `flatMapMerge` | Concurrent, interleaved | Batch processing, fan-out | `mergeMap` |
| `flatMapLatest` | Cancel previous | Search autocomplete | `switchMap` |

```kotlin
flowOf(1, 2, 3).flatMapMerge(concurrency = 2) { id -> fetchDetails(id) }

// Search-as-you-type pattern
searchQueryFlow()
    .debounce(300)              // wait 300ms after last keystroke
    .distinctUntilChanged()
    .filter { it.length >= 3 }
    .flatMapLatest { query -> flow { emit(searchApi(query)) } }
    .collect { println(it) }
```

## Threading: `flowOn`

`flowOn` changes the dispatcher for everything **upstream** of it:

```kotlin
flow { emit(readFileFromDisk()) }
    .map { parseData(it) }
    .flowOn(Dispatchers.IO)         // everything above runs on IO
    .map { processData(it) }
    .flowOn(Dispatchers.Default)    // this map runs on Default
    .collect { updateUI(it) }       // collect on caller's context
```

## Backpressure

Flow's collector controls the pace by default. Strategies when producer is faster:

| Strategy | Behavior | When to use | RxJS |
|---|---|---|---|
| Default | Producer waits for consumer | Data integrity critical | implicit |
| `buffer()` | Producer runs ahead, results queued | Speed matters | N/A |
| `conflate()` | Drop intermediate values | Only latest matters | `throttle`, `sample` |
| `collectLatest` | Cancel previous processing | Search/autocomplete | `switchMap` |

```kotlin
flow { for (i in 1..5) { delay(100); emit(i) } }
    .buffer()          // producer runs ahead
    .conflate()        // drop intermediates
    .collectLatest { value -> delay(300); println(value) }  // cancel slow processing
```

## Hot streams: SharedFlow & StateFlow

Cold flows produce per-collector. Hot flows share one stream across collectors.

### SharedFlow — event bus

```kotlin
val events = MutableSharedFlow<String>(replay = 0)  // replay=1: new collectors get last value

launch { events.collect { println("Collector 1: $it") } }
launch { events.collect { println("Collector 2: $it") } }
delay(100)  // give collectors time to start

events.emit("UserLoggedIn")   // both collectors receive
```

<Mermaid title="SharedFlow fan-out" code={`
flowchart LR
  E["MutableSharedFlow.emit"] --> C1["Collector 1"]
  E --> C2["Collector 2"]
  E --> C3["Collector N"]
`} height={300} />

RxJS equivalent: `Subject` (replay=0) or `ReplaySubject` (replay>0).

### StateFlow — observable state

Always has a current value. New collectors immediately get the latest. Only emits on change (deduplication).

```kotlin
val state = MutableStateFlow(AppState(count = 0, status = "idle"))

launch { state.collect { println("State: $it") } }

state.value = AppState(count = 1, status = "loading")
state.value = AppState(count = 1, status = "loading")  // no emission — same value
state.value = AppState(count = 2, status = "done")

// Atomic update — thread-safe
val counter = MutableStateFlow(0)
counter.update { it + 1 }   // safe from 100 coroutines
```

| Feature | SharedFlow | StateFlow |
|---|---|---|
| Initial value | No | Yes (required) |
| `.value` access | No | Always available |
| Deduplication | No | Yes |
| Replay | Configurable (0, 1, N) | Always 1 (latest) |
| Use case | Events | State |
| RxJS | `Subject`/`ReplaySubject` | `BehaviorSubject` |

### Converting cold → hot

```kotlin
val hotFlow = coldFlow.shareIn(
    scope = this,
    started = SharingStarted.Lazily,   // or Eagerly, WhileSubscribed(5000)
    replay = 1,
)

val stateFlow: StateFlow<Double> = priceStream().stateIn(
    scope = this,
    started = SharingStarted.WhileSubscribed(5000),
    initialValue = 100.0,
)
```

| SharingStarted | Behavior |
|---|---|
| `Eagerly` | Start immediately |
| `Lazily` | Start on first collector |
| `WhileSubscribed(timeout, expiry)` | Active while collectors exist |

## Exception handling

`catch` handles exceptions from **upstream** operators only — not from inside `collect`.

```kotlin
riskyFlow()
    .catch { e ->
        println("Caught: ${e.message}")
        emit(-1)   // can emit a fallback
    }
    .collect { println("Got: $it") }

// retry
unreliableFlow()
    .retry(retries = 3)
    .retryWhen { cause, attempt ->
        delay(100 * (attempt + 1))
        attempt < 5   // true = retry, false = give up
    }
```

:::caution[catch only sees upstream]
To handle collector errors, put logic in `onEach` and place `catch` after it, or wrap collection in try/catch.
:::

## Lifecycle operators

```kotlin
flowOf(1, 2, 3)
    .onStart { println("Flow starting...") }
    .onEach { println("Processing: $it") }
    .onCompletion { cause -> if (cause == null) println("Done") else println("Failed: ${cause.message}") }
    .collect()

emptyFlow<Int>()
    .onEmpty { emit(0) }   // emit default when empty
    .collect { println(it) }

// launchIn — collect in a separate coroutine
myFlow.onEach { process(it) }.launchIn(this)   // returns Job
```

## Converting between types

```kotlin
// Collection ↔ Flow
listOf(1, 2, 3).asFlow()
flowOf(1, 2, 3).toList()

// Channel ↔ Flow
channel.consumeAsFlow()
produce { flowOf(10, 20).collect { send(it) } }

// Sequence → Flow
sequence { yield(1) }.asFlow()
```

## Testing flows

```kotlin
@Test
fun `test flow collects expected values`() = runTest {
    val result = flowOf(1, 2, 3).map { it * 2 }.toList()
    assertEquals(listOf(2, 4, 6), result)
}

// Turbine — cleaner assertions on emissions
class TurbineTest {
    @Test
    fun `test flow emissions`() = runTest {
        flowOf(1, 2, 3).test {
            assertEquals(1, awaitItem())
            assertEquals(2, awaitItem())
            assertEquals(3, awaitItem())
            awaitComplete()
        }
    }

    @Test
    fun `test error flow`() = runTest {
        flow { emit(1); throw RuntimeException("boom") }.test {
            assertEquals(1, awaitItem())
            assertEquals("boom", awaitError().message)
        }
    }
}
```

## Real-world patterns

```kotlin
// Polling
fun pollEndpoint(intervalMs: Long): Flow<String> = flow {
    while (true) {
        emit(fetchStatus())
        delay(intervalMs)
    }
}

// Batch processing
fun <T> Flow<T>.chunked(size: Int): Flow<List<T>> = flow {
    val buffer = mutableListOf<T>()
    collect { value ->
        buffer.add(value)
        if (buffer.size >= size) { emit(buffer.toList()); buffer.clear() }
    }
    if (buffer.isNotEmpty()) emit(buffer.toList())
}

// Parallel processing
(1..20).asFlow()
    .flatMapMerge(concurrency = 5) { id -> flow { emit(processItem(id)) } }
    .collect { println(it) }
```
