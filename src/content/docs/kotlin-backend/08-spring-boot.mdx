Spring Boot is the JVM's most widely used web framework — the Express.js of TS-land or chi/gin in Go, but with auto-configuration, embedded server, DI, and monitoring built in.

## Mental model

| Concept | Express.js (TS) | Go (chi/gin) | Spring Boot (Kotlin) |
|---|---|---|---|
| Routing | `app.get("/path", handler)` | `r.Get("/path", handler)` | `@GetMapping("/path")` |
| Middleware | `app.use(middleware)` | `r.Use(middleware)` | Filters / Interceptors |
| DI container | tsyringe / InversifyJS | wire / manual | Built-in IoC container |
| Config | `dotenv` / config | envconfig / Viper | `application.yml` + `@ConfigurationProperties` |
| JSON | `JSON.parse` built-in | `encoding/json` | Jackson (auto-configured) |
| Validation | class-validator / Zod | validator | Jakarta Bean Validation |
| Health checks | terminus | custom handler | Actuator (built-in) |

:::tip[The trade-off]
Spring Boot is heavier: ~1-3s startup, ~100-300MB memory vs. milliseconds/10-50MB for Express/Go. It compensates with mature tooling and battle-tested production features. For something lighter, see [Module 09 (Ktor)](/kotlin-backend/09-ktor/).
:::

## Project setup

## Your first controller

```kotlin title="src/main/kotlin/com/example/taskapi/controller/HelloController.kt"
@RestController
class HelloController {

    @GetMapping("/hello")
    fun hello(): String = "Hello, World!"

    @GetMapping("/hello/json")
    fun helloJson(): Map<String, String> = mapOf("message" to "Hello, World!")
}
```

```bash
./gradlew bootRun
curl http://localhost:8080/hello        # Hello, World!
curl http://localhost:8080/hello/json   # {"message":"Hello, World!"}
```

| Annotation | Purpose | Express | Go |
|---|---|---|---|
| `@RestController` | HTTP handler class | router file | handler struct |
| `@GetMapping("/path")` | GET | `app.get` | `r.Get` |
| `@PostMapping` / `@PutMapping` / `@DeleteMapping` / `@PatchMapping` | other verbs | `app.post` etc. | `r.Post` etc. |
| `@RequestMapping("/api")` | base path prefix | `Router("/api")` | `r.Route("/api", ...)` |

### Full CRUD controller

```kotlin title="src/main/kotlin/com/example/taskapi/controller/TaskController.kt"
@RestController
@RequestMapping("/api/tasks")
class TaskController(
    private val taskService: TaskService    // injected by Spring
) {

    @GetMapping
    fun getAllTasks(): List<TaskResponse> = taskService.findAll()

    @GetMapping("/{id}")
    fun getTask(@PathVariable id: String): TaskResponse = taskService.findById(id)

    @PostMapping
    fun createTask(@RequestBody request: CreateTaskRequest): ResponseEntity<TaskResponse> {
        val task = taskService.create(request)
        return ResponseEntity
            .created(URI.create("/api/tasks/${task.id}"))
            .body(task)
    }

    @PutMapping("/{id}")
    fun updateTask(@PathVariable id: String, @RequestBody request: UpdateTaskRequest): TaskResponse =
        taskService.update(id, request)

    @DeleteMapping("/{id}")
    @ResponseStatus(HttpStatus.NO_CONTENT)
    fun deleteTask(@PathVariable id: String) { taskService.delete(id) }

    @GetMapping("/status/{status}")
    fun getTasksByStatus(@PathVariable status: String): List<TaskResponse> =
        taskService.findByStatus(status)

    @GetMapping("/search")
    fun searchTasks(@RequestParam q: String): List<TaskResponse> = taskService.search(q)
}
```

- Spring auto-serializes return values to JSON (no `res.json()` needed).
- `@PathVariable` extracts from URL path (like `req.params.id`). Spring coerces types.
- `@RequestParam` reads query params. Optional: nullable + `required = false`, or `defaultValue`.
- `@RequestBody` deserializes JSON body to a Kotlin class.
- `ResponseEntity<T>` gives full control over status/headers.

### ResponseEntity for full control

```kotlin
@PostMapping
fun createTask(@RequestBody request: CreateTaskRequest): ResponseEntity<TaskResponse> {
    val task = taskService.create(request)
    return ResponseEntity
        .status(HttpStatus.CREATED)                        // 201
        .header("X-Task-Id", task.id)
        .location(URI.create("/api/tasks/${task.id}"))
        .body(task)
}

@GetMapping("/{id}")
fun getTask(@PathVariable id: String): ResponseEntity<TaskResponse> {
    val task = taskService.findByIdOrNull(id)
        ?: return ResponseEntity.notFound().build()       // 404
    return ResponseEntity.ok(task)                        // 200
}

@DeleteMapping("/{id}")
fun deleteTask(@PathVariable id: String): ResponseEntity<Void> {
    taskService.delete(id)
    return ResponseEntity.noContent().build()             // 204
}
```

## Dependency injection

Request flows through layers Spring wires:

<Mermaid title="Request flow through layers" code={`
flowchart LR
  C["HTTP Client"] -->|"JSON request"| Ctrl["@RestController"]
  Ctrl --> Svc["@Service"]
  Svc --> Repo["@Repository"]
  Repo --> DB[("Data store")]
  Repo -->|"domain model"| Svc
  Svc -->|"DTO"| Ctrl
  Ctrl -->|"JSON response"| C
`} />

Declare dependencies as constructor parameters — Spring builds the graph:

```kotlin
@RestController
class TaskController(private val taskService: TaskService)   // injected

@Service
class TaskService(private val taskRepository: TaskRepository)  // injected

@Repository
class TaskRepository    // singleton created by Spring
```

| Annotation | Layer |
|---|---|
| `@Component` | Generic bean |
| `@Service` | Business logic |
| `@Repository` | Data access |
| `@RestController` / `@Controller` | HTTP layer |
| `@Configuration` | Bean definitions, config |

## Error handling

Custom exceptions carry meaning; `@RestControllerAdvice` maps each to a structured response.

```kotlin title="src/main/kotlin/com/example/taskapi/exception/Exceptions.kt"
class TaskNotFoundException(val taskId: String) :
    RuntimeException("Task not found: $taskId")

class TaskLimitExceededException(message: String) : RuntimeException(message)

class InvalidTaskStatusException(val status: String) :
    RuntimeException("Invalid task status: $status. Valid values: TODO, IN_PROGRESS, DONE")
```

```kotlin title="src/main/kotlin/com/example/taskapi/exception/GlobalExceptionHandler.kt"
data class ErrorResponse(
    val status: Int,
    val error: String,
    val message: String,
    val timestamp: Instant = Instant.now(),
    val details: Map<String, String>? = null
)

@RestControllerAdvice
class GlobalExceptionHandler {

    @ExceptionHandler(TaskNotFoundException::class)
    fun handleNotFound(ex: TaskNotFoundException): ResponseEntity<ErrorResponse> =
        ResponseEntity.status(HttpStatus.NOT_FOUND).body(
            ErrorResponse(404, "Not Found", ex.message ?: "Resource not found")
        )

    @ExceptionHandler(MethodArgumentNotValidException::class)
    fun handleValidation(ex: MethodArgumentNotValidException): ResponseEntity<ErrorResponse> {
        val details = ex.bindingResult.fieldErrors.associate { it.field to (it.defaultMessage ?: "Invalid") }
        return ResponseEntity.status(HttpStatus.BAD_REQUEST).body(
            ErrorResponse(400, "Validation Failed", "Request validation failed", details = details)
        )
    }

    @ExceptionHandler(Exception::class)
    fun handleGeneric(ex: Exception): ResponseEntity<ErrorResponse> =
        ResponseEntity.status(HttpStatus.INTERNAL_SERVER_ERROR).body(
            ErrorResponse(500, "Internal Server Error", "An unexpected error occurred")
        )
}
```

```json
  "error": "Not Found",
  "message": "Task not found: abc-123",
  "timestamp": "2026-02-10T12:00:00Z",
  "details": null
}
```

## Validation

Jakarta Bean Validation via `spring-boot-starter-validation`. Add constraints to DTO fields with `@field:` prefix:

```kotlin title="src/main/kotlin/com/example/taskapi/dto/CreateTaskRequest.kt"
data class CreateTaskRequest(
    @field:NotBlank(message = "Title is required")
    @field:Size(min = 1, max = 200, message = "Title must be 1-200 characters")
    val title: String,

    @field:Size(max = 2000, message = "Description must be at most 2000 characters")
    val description: String = "",

    @field:Pattern(regexp = "LOW|MEDIUM|HIGH|CRITICAL", message = "Priority must be one of: LOW, MEDIUM, HIGH, CRITICAL")
    val priority: String = "MEDIUM"
)
```

:::caution[Use the `@field:` prefix]
Without it, the annotation lands on the constructor parameter, not the field — validation silently does nothing.
:::

Activate with `@Valid` on the `@RequestBody`:

```kotlin
@PostMapping
fun createTask(@Valid @RequestBody request: CreateTaskRequest): ResponseEntity<TaskResponse>
```

| Annotation | Purpose | TS (class-validator) | Go (validator) |
|---|---|---|---|
| `@NotBlank` | not null/empty/whitespace | `@IsNotEmpty()` | `validate:"required"` |
| `@NotNull` | not null | `@IsDefined()` | `validate:"required"` |
| `@Size(min, max)` | length | `@Length(min, max)` | `validate:"min=1,max=200"` |
| `@Min` / `@Max` | number range | `@Min()` / `@Max()` | `validate:"min=0,max=100"` |
| `@Email` | email format | `@IsEmail()` | `validate:"email"` |
| `@Pattern(regexp)` | regex match | `@Matches(regex)` | `validate:"oneof=A B C"` |
| `@Positive` | number > 0 | `@IsPositive()` | `validate:"gt=0"` |

### Custom validator

```kotlin
@Target(AnnotationTarget.FIELD)
@Retention(AnnotationRetention.RUNTIME)
@Constraint(validatedBy = [NoSwearWordsValidator::class])
annotation class NoSwearWords(
    val message: String = "Contains inappropriate language",
    val groups: Array<KClass<*>> = [],
    val payload: Array<KClass<out Payload>> = []
)

class NoSwearWordsValidator : ConstraintValidator<NoSwearWords, String> {
    private val blocked = setOf("badword1", "badword2")
    override fun isValid(value: String?, context: ConstraintValidatorContext?): Boolean =
        value == null || blocked.none { value.lowercase().contains(it) }
}
```

## Jackson and Kotlin

`jackson-module-kotlin` makes Jackson work with Kotlin data classes — deserializes into constructors, handles nullability and defaults.

```yaml title="application.yml"
spring:
  jackson:
    default-property-inclusion: non_null      # skip null fields
    serialization:
      write-dates-as-timestamps: false         # ISO-8601 dates
    deserialization:
      fail-on-unknown-properties: false         # ignore extra fields
```

```kotlin
// Defaults work: missing JSON field uses Kotlin default
data class CreateTaskRequest(
    val title: String,
    val description: String = "",
    val priority: String = "MEDIUM"
)

// Custom JSON values
enum class Priority {
    @JsonProperty("low") LOW,
    @JsonProperty("medium") MEDIUM,
    @JsonProperty("high") HIGH,
    @JsonProperty("critical") CRITICAL
}

// Sealed classes with discriminator
@JsonTypeInfo(use = JsonTypeInfo.Id.NAME, property = "type")
@JsonSubTypes(
    JsonSubTypes.Type(value = NotificationEvent.TaskCreated::class, name = "task_created"),
    JsonSubTypes.Type(value = NotificationEvent.TaskCompleted::class, name = "task_completed")
)
sealed class NotificationEvent {
    data class TaskCreated(val taskId: String, val title: String) : NotificationEvent()
    data class TaskCompleted(val taskId: String, val completedBy: String) : NotificationEvent()
}

// Hide/rename fields
data class User(
    val id: String,
    val email: String,
    @JsonIgnore val passwordHash: String
)

data class TaskResponse(
    val id: String,
    @JsonProperty("created_at") val createdAt: Instant
)
```

## Middleware: filters

Servlet filters run before/after the controller — the Express middleware equivalent.

```kotlin
@Component
@Order(1)
class RequestLoggingFilter : OncePerRequestFilter() {

    override fun doFilterInternal(
        request: HttpServletRequest,
        response: HttpServletResponse,
        filterChain: FilterChain
    ) {
        val start = System.currentTimeMillis()
        val requestId = request.getHeader("X-Request-Id") ?: UUID.randomUUID().toString()
        response.setHeader("X-Request-Id", requestId)

        try {
            filterChain.doFilter(request, response)
        } finally {
            val duration = System.currentTimeMillis() - start
            logger.info("{} {} {} - {}ms [{}]",
                request.method, request.requestURI, response.status, duration, requestId)
        }
    }
}
```

## Framework comparison

| Feature | Express.js (TS) | Go (chi/gin) | Spring Boot (Kotlin) |
|---|---|---|---|
| Startup time | ~100ms | ~10ms | ~1-3s |
| Memory usage | ~30-80MB | ~10-30MB | ~100-300MB |
| JSON parsing | built-in | `encoding/json` | Jackson (auto) |
| Validation | class-validator / Zod | validator | Jakarta Bean Validation |
| DI | tsyringe / manual | wire / manual | Built-in IoC container |
| Health checks | manual / terminus | manual | Actuator (built-in) |
| Metrics | prom-client | prometheus/client_golang | Micrometer (built-in) |
| ORM | Prisma / TypeORM | GORM / sqlc | Spring Data JPA / Exposed |
| Testing | Jest + Supertest | testing + httptest | MockMvc / WebTestClient |
| Hot reload | nodemon | air | Spring DevTools |
| Concurrency | event loop | goroutines | virtual threads / coroutines |
