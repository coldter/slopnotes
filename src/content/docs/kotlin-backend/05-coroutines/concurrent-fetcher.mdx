## Goal

Build a fetcher that fans out one coroutine per URL, gates them through a `Semaphore`, times each out, and fans results back in as a typed list.

## What you'll build

1. `ConcurrentFetcher` with `maxConcurrency: Int`, `timeoutMs: Long`, `fetchAll(urls): List<FetchResult>`.
2. Sealed `FetchResult`: `Success(url, body, durationMs)` / `Failure(url, error, durationMs)`.
3. Concurrency control via `Semaphore` (or `limitedParallelism`).
4. Per-request timeout via `withTimeoutOrNull`.
5. Summary output: succeeded, failed, total time.

### The result type

Sealed class — `when` over it is exhaustive, no `else`.

```kotlin title="src/main/kotlin/Main.kt"
sealed class FetchResult {
    abstract val url: String
    abstract val durationMs: Long

    data class Success(
        override val url: String,
        val body: String,
        override val durationMs: Long,
    ) : FetchResult()

    data class Failure(
        override val url: String,
        val error: String,
        override val durationMs: Long,
    ) : FetchResult()
}
```

### The fetcher

Three coroutine tools do all the work:

```kotlin title="src/main/kotlin/Main.kt" {5,8-16,21-26}
class ConcurrentFetcher(
    private val maxConcurrency: Int = 5,
    private val timeoutMs: Long = 5000,
) {
    private val semaphore = Semaphore(maxConcurrency)

    suspend fun fetchAll(urls: List<String>): List<FetchResult> = coroutineScope {
        urls.map { url ->
            async {
                semaphore.withPermit {
                    fetchOne(url)
                }
            }
        }.awaitAll()
    }

    private suspend fun fetchOne(url: String): FetchResult {
        val start = System.currentTimeMillis()
        return try {
            val body = withTimeoutOrNull(timeoutMs) {
                doFetch(url)
            }
            val elapsed = System.currentTimeMillis() - start
            if (body != null) {
                FetchResult.Success(url, body, elapsed)
            } else {
                FetchResult.Failure(url, "Timeout after ${timeoutMs}ms", elapsed)
            }
        } catch (e: Exception) {
            val elapsed = System.currentTimeMillis() - start
            FetchResult.Failure(url, e.message ?: "Unknown error", elapsed)
        }
    }
}
```

- **`coroutineScope`** — structured-concurrency boundary. `fetchAll` doesn't return until every child completes; one fatal failure cancels the rest. The `WaitGroup` you never forget.
- **`async` + `awaitAll()`** — fan-out/fan-in. One coroutine per URL; `awaitAll` collects into `List<FetchResult>`.
- **`semaphore.withPermit`** — caps concurrency. All N coroutines launch, but only `maxConcurrency` are inside `fetchOne` at once; the rest suspend waiting for a permit.
- **`withTimeoutOrNull`** — races the fetch against a clock. Returns null on timeout (we prefer the `OrNull` variant to convert timeout into `Failure`, not an exception). The surrounding try/catch converts other exceptions into `Failure` too.

### The simulated fetch

To stay dependency-free, `doFetch` fakes a network call (random delay + 10% failure rate). Swap in a real JDK `HttpClient` wrapped in `withContext(Dispatchers.IO)` for production.

```kotlin title="src/main/kotlin/Main.kt"
private suspend fun doFetch(url: String): String {
    val delayMs = (100L..2000L).random()
    delay(delayMs)

    if ((1..10).random() == 1) {
        throw RuntimeException("Connection refused: $url")
    }

    return "<!DOCTYPE html><html><body>Response from $url (${delayMs}ms)</body></html>"
}
```

:::note[Why `delay`, not `Thread.sleep`]
`delay` parks the coroutine and frees the thread. `Thread.sleep` blocks the thread, defeating the `Semaphore` cap.
:::

### main

```kotlin title="src/main/kotlin/Main.kt" {1,12,18-26,29-32}
fun main() = runBlocking {
    val urls = listOf(
        "https://example.com",
        "https://httpbin.org/get",
        "https://jsonplaceholder.typicode.com/posts/1",
        "https://api.github.com",
        "https://httpbin.org/delay/1",
        // … more URLs …
    )

    val fetcher = ConcurrentFetcher(maxConcurrency = 3, timeoutMs = 3000)

    println("Fetching ${urls.size} URLs with max concurrency 3...")
    println("=" .repeat(60))

    val start = System.currentTimeMillis()
    val results = fetcher.fetchAll(urls)
    val totalTime = System.currentTimeMillis() - start

    results.forEach { result ->
        when (result) {
            is FetchResult.Success ->
                println("[OK]   ${result.url} (${result.durationMs}ms) - ${result.body.take(50)}...")
            is FetchResult.Failure ->
                println("[FAIL] ${result.url} (${result.durationMs}ms) - ${result.error}")
        }
    }

    val successes = results.count { it is FetchResult.Success }
    val failures = results.count { it is FetchResult.Failure }
    println("=" .repeat(60))
    println("Total: ${results.size} | Success: $successes | Failed: $failures | Time: ${totalTime}ms")
}
```

With cap 3, wall-clock time is roughly `ceil(N/3)` waves — the speedup the `Semaphore` buys over sequential fetching.
