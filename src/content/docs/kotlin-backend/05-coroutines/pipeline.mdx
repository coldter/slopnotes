## Goal

Build a five-stage pipeline using coroutine channels. Each stage is its own coroutine reading from an input channel and emitting onto a new one — streams concurrently, shuts down cleanly when the source dries up.

## What you'll build

<Steps>

1. **Producer** — generates `1..N` on a `ReceiveChannel<Int>`.
2. **Square** — reads, emits `value * value` (with fan-out workers).
3. **Filter** — keeps values above a threshold.
4. **Format** — converts to `String`.
5. **Consumer** — collects and prints.

</Steps>

### The producer

`produce { }` launches a coroutine, hands you a `ProducerScope<T>`, returns a `ReceiveChannel<T>`. **The channel closes automatically when the block finishes** — no manual `close()`, no Go-style `defer close(ch)`. `capacity = 10` gives backpressure.

```kotlin title="src/main/kotlin/Main.kt" {1,3}
fun CoroutineScope.produceNumbers(count: Int): ReceiveChannel<Int> = produce(capacity = 10) {
    for (i in 1..count) send(i)
    println("[Producer] Sent $count numbers, closing.")
}
```

### Stage 1 — Square (with fan-out)

`workers` child coroutines all read from the *same* input channel — each item goes to exactly one worker (load balancing). An `AtomicInteger` tallies safely.

```kotlin title="src/main/kotlin/Main.kt" {7-14,16}
fun CoroutineScope.squareStage(
    input: ReceiveChannel<Int>,
    workers: Int = 1,
): ReceiveChannel<Long> = produce(capacity = 10) {
    val processed = AtomicInteger(0)
    val jobs = (1..workers).map { workerId ->
        launch {
            for (value in input) {
                val squared = value.toLong() * value.toLong()
                send(squared)
                processed.incrementAndGet()
            }
        }
    }
    jobs.forEach { it.join() }
    println("[Square]   Processed ${processed.get()} items with $workers worker(s).")
}
```

:::note[Why `for (value in input)` drains cleanly]
Iterating a `ReceiveChannel` with `for` receives until closed *and* empty, then exits — no sentinel, no `v, ok := <-ch` like Go. Upstream `produce` closes its channel, so every worker loop ends on its own.
:::

### Stage 2 — Filter

```kotlin title="src/main/kotlin/Main.kt" {6-12}
fun CoroutineScope.filterStage(
    input: ReceiveChannel<Long>,
    threshold: Long,
): ReceiveChannel<Long> = produce(capacity = 10) {
    var passed = 0
    var dropped = 0
    for (value in input) {
        if (value > threshold) { send(value); passed++ }
        else { dropped++ }
    }
    println("[Filter]   Passed $passed, dropped $dropped (threshold > $threshold).")
}
```

### Stage 3 — Format

```kotlin title="src/main/kotlin/Main.kt"
fun CoroutineScope.formatStage(
    input: ReceiveChannel<Long>,
): ReceiveChannel<String> = produce(capacity = 10) {
    var count = 0
    for (value in input) {
        send("Result: $value")
        count++
    }
    println("[Format]   Formatted $count items.")
}
```

### The consumer

Terminal stage — not a `produce`, just a `suspend fun` that loops the final channel into a list.

```kotlin title="src/main/kotlin/Main.kt"
suspend fun consume(input: ReceiveChannel<String>): List<String> {
    val results = mutableListOf<String>()
    for (value in input) results.add(value)
    return results
}
```

### Wiring it together

`runBlocking` provides the scope; it won't return until all child coroutines finish. Chaining stages is just piping output → input.

```kotlin title="src/main/kotlin/Main.kt" {10-15}
fun main() = runBlocking {
    val count = 100
    val threshold = 50L
    val workerCount = 3

    println("Pipeline: produce(1..$count) -> square(x$workerCount) -> filter(>$threshold) -> format -> consume")
    println("=".repeat(80))

    val results: List<String>
    val elapsed = measureTimeMillis {
        val numbers = produceNumbers(count)
        val squared = squareStage(numbers, workers = workerCount)
        val filtered = filterStage(squared, threshold)
        val formatted = formatStage(filtered)
        results = consume(formatted)
    }

    println("=".repeat(80))
    println("Results (${results.size} items):")
    results.take(10).forEach { println("  $it") }
    if (results.size > 10) println("  ... and ${results.size - 10} more")

    println("=".repeat(80))
    val throughput = if (elapsed > 0) results.size * 1000.0 / elapsed else 0.0
    println("Total time: ${elapsed}ms")
    println("Throughput: ${"%.1f".format(throughput)} items/sec")
    println("Pipeline complete.")
}
```

Imports at the top of the file:

```kotlin title="src/main/kotlin/Main.kt"
import kotlinx.coroutines.*
import kotlinx.coroutines.channels.*
import java.util.concurrent.atomic.AtomicInteger
import kotlin.system.measureTimeMillis
```

:::tip[Coming from Go]
`produce { }` is "a goroutine that owns its output channel and closes it on return," `for (value in input)` is `for value := range ch`, and `runBlocking` waiting for all stages is what a `sync.WaitGroup` buys you manually. The win: closing and draining are automatic — you never forget a `close(ch)`.
:::

## Run it

<Steps>
