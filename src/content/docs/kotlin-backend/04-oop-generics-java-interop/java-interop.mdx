## Goal

Practice two-way interop in one project: call Java stdlib and your own Java code from Kotlin, then make Kotlin classes comfortable from Java. `.java` and `.kt` files compile together — the friction is nullability and naming.

## Requirements

1. Read Java stdlib types from Kotlin, handle nullability safely.
2. Call a custom Java service, treating returns as platform types.
3. Use SAM conversion for Java functional interfaces.
4. Write Kotlin classes annotated so Java calls them naturally.
5. Java calls back into Kotlin to prove the round trip.

:::note[TS/Go mental model]
No real analogue in TS or Go — this is a JVM superpower. A platform type (`T!`) means "Java didn't tell me if this is null." Treat it as nullable.
:::

## The worked solution

A single Gradle module with both `.java` and `.kt` under the same package.

<FileTree>
- java-interop/
  - build.gradle.kts kotlin + java + application plugins
  - settings.gradle.kts
  - src/main/
    - kotlin/com/example/interop/
      - **Main.kt** entry point, drives every demo
      - MoneyUtils.kt BigDecimal arithmetic
      - TimeUtils.kt java.time calculations
      - KotlinForJava.kt classes designed for Java callers
    - java/com/example/interop/
      - JavaService.java Java class called from Kotlin
      - JavaCaller.java Java code calling Kotlin
</FileTree>

### build.gradle.kts

Three plugins together: `kotlin("jvm")` compiles `.kt`, `java` compiles `.java`, `application` wires `./gradlew run`. `jvmToolchain(21)` pins both to the same JDK.

```kotlin title="build.gradle.kts" {2-4,14-16}
plugins {
    kotlin("jvm") version "2.1.0"
    java
    application
}

group = "com.example"
version = "1.0-SNAPSHOT"

repositories {
    mavenCentral()
}

kotlin {
    jvmToolchain(21)
}

dependencies {
    testImplementation(kotlin("test"))
}

tasks.test {
    useJUnitPlatform()
}

application {
    mainClass.set("com.example.interop.MainKt")
}
```

```kotlin title="settings.gradle.kts"
rootProject.name = "java-interop"
```

### MoneyUtils.kt — BigDecimal from Kotlin

Kotlin's operator overloading makes `BigDecimal` read like primitive math. Rule: build from **String**, never `Double`.

```kotlin title="src/main/kotlin/com/example/interop/MoneyUtils.kt" {12-13,47-48,51-54}
package com.example.interop

import java.math.BigDecimal
import java.math.RoundingMode

object MoneyUtils {

    fun money(amount: String): BigDecimal =
        BigDecimal(amount).setScale(2, RoundingMode.HALF_UP)

    fun calculateTax(subtotal: BigDecimal, taxRate: BigDecimal): BigDecimal =
        (subtotal * taxRate).setScale(2, RoundingMode.HALF_UP)

    fun calculateDiscount(amount: BigDecimal, discountPercent: BigDecimal): BigDecimal =
        (amount * discountPercent).setScale(2, RoundingMode.HALF_UP)

    fun demo() {
        println("--- BigDecimal Money Arithmetic ---")

        val price = money("19.99")
        val quantity = BigDecimal("3")
        val subtotal = price * quantity
        val tax = calculateTax(subtotal, BigDecimal("0.08"))
        val total = subtotal + tax
        val discount = calculateDiscount(total, BigDecimal("0.10"))
        val finalAmount = total - discount

        println("Price: $price")
        println("Subtotal: ${subtotal.setScale(2, RoundingMode.HALF_UP)}")
        println("Tax (8%): $tax")
        println("Total: ${total.setScale(2, RoundingMode.HALF_UP)}")
        println("Discount (10%): $discount")
        println("Final: ${finalAmount.setScale(2, RoundingMode.HALF_UP)}")

        println()
        println("Why not Double?")
        println("  Double: 0.1 + 0.2 = ${0.1 + 0.2}")
        println("  BigDecimal: 0.1 + 0.2 = ${BigDecimal("0.1") + BigDecimal("0.2")}")

        val a = BigDecimal("1.0")
        val b = BigDecimal("1.00")
        println("  1.0 == 1.00 (equals): ${a == b}")              // false — scale differs
        println("  1.0 compareTo 1.00: ${a.compareTo(b) == 0}")   // true — same value
    }
}
```

:::caution[`==` is not `compareTo` for BigDecimal]
`BigDecimal("1.0") == BigDecimal("1.00")` is **false** — `equals` compares scale too. Use `a.compareTo(b) == 0` for numeric equality.
:::

### TimeUtils.kt — java.time from Kotlin

```kotlin title="src/main/kotlin/com/example/interop/TimeUtils.kt" {50,68-78,81-96}
package com.example.interop

import java.time.*
import java.time.format.DateTimeFormatter
import java.time.temporal.ChronoUnit

object TimeUtils {

    fun demo() {
        println("--- java.time Date/Time Operations ---")

        val now = Instant.now()
        val today = LocalDate.now()
        val zoned = ZonedDateTime.now(ZoneId.of("UTC"))
        println("Now (UTC): $zoned")
        println("Today: $today")

        val sampleDate = LocalDate.of(2024, 1, 15)
        println("Formatted: ${sampleDate.format(DateTimeFormatter.ofPattern("MMMM d, yyyy"))}")
        println("Parsed: ${LocalDate.parse("2024-03-15")}")

        println("30 days from now: ${today.plusDays(30)}")

        val endOfYear = LocalDate.of(today.year, 12, 31)
        println("Days until new year: ${ChronoUnit.DAYS.between(today, endOfYear)}")

        val businessDays = countBusinessDays(LocalDate.of(2024, 1, 1), LocalDate.of(2024, 1, 31))
        println("Business days Jan 2024: $businessDays")

        // `in` compiles to a contains() call on the Java list
        val isWeekend = today.dayOfWeek in listOf(DayOfWeek.SATURDAY, DayOfWeek.SUNDAY)
        println("Is weekend: $isWeekend")

        val duration = Duration.between(LocalTime.of(9, 0), LocalTime.of(17, 30))
        println("Work day duration: ${duration.toHours()}h ${duration.toMinutesPart()}m")
    }

    fun countBusinessDays(start: LocalDate, end: LocalDate): Long {
        var count = 0L
        var current = start
        while (current.isBefore(end) || current == end) {
            if (current.dayOfWeek !in listOf(DayOfWeek.SATURDAY, DayOfWeek.SUNDAY)) count++
            current = current.plusDays(1)
        }
        return count
    }

    fun parseFlexible(dateStr: String): LocalDate? {
        val formats = listOf(
            DateTimeFormatter.ISO_LOCAL_DATE,             // 2024-01-15
            DateTimeFormatter.ofPattern("MM/dd/yyyy"),    // 01/15/2024
            DateTimeFormatter.ofPattern("dd-MM-yyyy"),    // 15-01-2024
            DateTimeFormatter.ofPattern("yyyy.MM.dd"),    // 2024.01.15
        )
        for (fmt in formats) {
            try { return LocalDate.parse(dateStr, fmt) } catch (_: Exception) { continue }
        }
        return null
    }
}
```

### JavaService.java — the Java code Kotlin calls

Plain Java with no nullability annotations — so Kotlin sees platform types. `findUserName` can return null. `Transformer<T, R>` is `@FunctionalInterface` for SAM conversion.

```java title="src/main/java/com/example/interop/JavaService.java" {19-22,30-32,45-48}
package com.example.interop;

import java.util.*;

public class JavaService {

    private final Map<String, String> users = new HashMap<>();

    public JavaService() {
        users.put("u1", "Alice");
        users.put("u2", "Bob");
        users.put("u3", null);  // intentional null
    }

    // Returns String! (platform type) — can be null
    public String findUserName(String id) {
        return users.get(id);
    }

    public List<String> getAllNames() {
        return new ArrayList<>(users.values());  // may contain null
    }

    public Optional<String> findUserNameOptional(String id) {
        return Optional.ofNullable(users.get(id));
    }

    @FunctionalInterface
    public interface Transformer<T, R> {
        R transform(T input);
    }

    public <T, R> List<R> mapValues(List<T> items, Transformer<T, R> transformer) {
        List<R> result = new ArrayList<>();
        for (T item : items) result.add(transformer.transform(item));
        return result;
    }

    public List<String> filterNames(java.util.function.Predicate<String> predicate) {
        List<String> result = new ArrayList<>();
        for (String name : users.values()) {
            if (name != null && predicate.test(name)) result.add(name);
        }
        return result;
    }
}
```

:::caution[Always treat Java returns as nullable]
A Java method with no annotation gives Kotlin a platform type like `String!`. Assign to `String?` unless the Java is `@NotNull`. A real null into a non-null `String` throws at runtime.
:::

### Main.kt — calling Java from Kotlin

```kotlin title="src/main/kotlin/com/example/interop/Main.kt" {31-32,39-41,57,72-73,76,80,86-89,100}
package com.example.interop

import java.util.concurrent.Callable
import java.util.concurrent.Executors

fun main() {
    println("=== Java Interop Demo ===")
    println()

    MoneyUtils.demo()
    println()
    TimeUtils.demo()
    println()

    // Platform types
    println("--- Calling Java from Kotlin (platform types) ---")
    val service = JavaService()

    val name: String? = service.findUserName("u1")   // capture as nullable
    println("Java service returned: $name")

    val missing: String? = service.findUserName("u999")
    println("Null-safe handling: ${missing ?: "not found"}")

    val allNames: List<String?> = service.getAllNames()
    println("Java list (watch for nulls): $allNames")
    println("Filtered non-null: ${allNames.filterNotNull()}")
    println()

    // Optional handling
    println("--- Optional Handling ---")
    val kotlinNullable: String? = service.findUserNameOptional("u1").orElse(null)
    println("Kotlin-style (nullable): $kotlinNullable")
    println()

    // SAM conversions — Kotlin lambdas into Java single-method interfaces
    println("--- SAM Conversions ---")
    val names = mutableListOf("Alice", "Bob", "Charlie")

    names.sortWith { a, b -> a.length - b.length }           // Comparator
    println("Sorted by length: $names")

    val filtered = service.filterNames { it.length > 3 }     // Predicate
    println("Filtered (Predicate SAM): $filtered")

    val uppercased = service.mapValues(listOf("Alice", "Bob")) { it.uppercase() }  // Transformer
    println("Mapped (Transformer SAM): $uppercased")

    val executor = Executors.newSingleThreadExecutor()
    try {
        val future = executor.submit(Callable { "Task on ${Thread.currentThread().name}" })
        println("Executor result: ${future.get()}")
    } finally {
        executor.shutdown()
    }
    println()

    // Java calls back into Kotlin
    JavaCaller.demonstrate()
    println()

    // @JvmName functions from Kotlin side
    println("--- @JvmName Usage ---")
    println("Sum of ints: ${listOf(1, 2, 3).sumAll()}")
    println("Join strings: ${listOf("hello", "world").sumAll()}")
    println("Slugified: ${"Hello World! From Kotlin".slugify()}")
}
```

:::tip[`Optional.orElse(null)` is the bridge]
Collapse `Optional<T>` to `T?` at the boundary — `service.findUserNameOptional(id).orElse(null)` gives you a `String?` you can use with `?:`, `?.`, `let`. Don't carry `Optional` deep into Kotlin code.
:::

### KotlinForJava.kt — making Kotlin Java-friendly

Without annotations, Java sees odd shapes: `UserConfig.Companion.createDefault()`, default params vanish, top-level functions land in `KotlinForJavaKt`. The `@Jvm…` annotations fix each:

- `@file:JvmName("KotlinUtils")` — Java calls `KotlinUtils.greet(...)` not `KotlinForJavaKt.greet(...)`
- `@JvmOverloads` — generates overloads per default param
- `@JvmStatic` — lifts companion functions to real statics
- `@JvmField` — exposes `MAX_USERS` as a bare field
- `@JvmName("sumOfInts")` / `@JvmName("joinStrings")` — distinct names for erased-clashing extensions

```kotlin title="src/main/kotlin/com/example/interop/KotlinForJava.kt" {1,11-12,18-23,46-47,52,60-64}
@file:JvmName("KotlinUtils")

package com.example.interop

class KotlinForJava {

    data class UserConfig @JvmOverloads constructor(
        val maxUsers: Int = 100,
        val defaultRole: String = "viewer",
        val debugMode: Boolean = false
    ) {
        companion object {
            @JvmField
            val MAX_USERS = 1000

            @JvmStatic
            fun createDefault(): UserConfig = UserConfig()

            @JvmStatic
            fun fromEnv(): UserConfig {
                val maxUsers = System.getenv("MAX_USERS")?.toIntOrNull() ?: 100
                val role = System.getenv("DEFAULT_ROLE") ?: "viewer"
                val debug = System.getenv("DEBUG")?.toBoolean() ?: false
                return UserConfig(maxUsers, role, debug)
            }
        }
    }
}

fun formatFullName(first: String, last: String): String = "$first $last".trim()

@JvmOverloads
fun greet(name: String, greeting: String = "Hello"): String = "$greeting, $name!"

fun String.slugify(): String =
    lowercase().replace(Regex("[^a-z0-9\\s-]"), "").replace(Regex("\\s+"), "-").trim('-')

@JvmName("sumOfInts")
fun List<Int>.sumAll(): Int = this.sum()

@JvmName("joinStrings")
fun List<String>.sumAll(): String = this.joinToString(", ")
```

### JavaCaller.java — Java calling back into Kotlin

```java title="src/main/java/com/example/interop/JavaCaller.java" {17,21,25,29,35,46-47}
package com.example.interop;

public class JavaCaller {

    public static void demonstrate() {
        System.out.println("--- Kotlin Called from Java ---");

        // @JvmOverloads: all defaults
        KotlinForJava.UserConfig config1 = new KotlinForJava.UserConfig();
        System.out.println("UserConfig: " + config1);

        // Partial defaults via @JvmOverloads
        KotlinForJava.UserConfig config2 = new KotlinForJava.UserConfig(50, "admin", true);
        System.out.println("UserConfig (custom): " + config2);

        // @JvmStatic: companion method as static
        KotlinForJava.UserConfig config3 = KotlinForJava.UserConfig.createDefault();

        // @JvmField: bare field access
        int maxUsers = KotlinForJava.UserConfig.MAX_USERS;
        System.out.println("Field access: " + maxUsers);

        // @file:JvmName("KotlinUtils")
        String formatted = KotlinUtils.formatFullName("John", "Doe");
        System.out.println("Top-level function: " + formatted);

        String greeting1 = KotlinUtils.greet("Alice");
        String greeting2 = KotlinUtils.greet("Alice", "Hi");
        System.out.println("Greet (default): " + greeting1);
        System.out.println("Greet (custom): " + greeting2);

        // Extension function: receiver becomes first param
        String slugified = KotlinUtils.slugify("Hello World From Java");
        System.out.println("Extension (slugify): " + slugified);
    }
}
```
