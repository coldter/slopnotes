Kotlin's stdlib gives TS-level convenience with Go-level performance control. Collections are **immutable by default** — you opt into mutability with `MutableList`/`MutableSet`/`MutableMap`.

## The collection hierarchy

```text
Iterable<T>
└── Collection<T>          // read-only: size, contains, iterator
    ├── List<T>            // ordered, indexed, duplicates allowed
    ├── Set<T>             // unique elements
    └── MutableCollection<T>
        ├── MutableList<T>
        └── MutableSet<T>

Map<K,V>                   // read-only
└── MutableMap<K,V>        // put, remove
```

## Transformations

```kotlin
val names = listOf("alice", "bob", "charlie")
names.map { it.uppercase() }                          // [ALICE, BOB, CHARLIE]
names.mapIndexed { i, name -> "$i: $name" }
listOf("1", "two", "3").mapNotNull { it.toIntOrNull() }  // [1, 3]

listOf(1, 2, 3, 4, 5).filter { it % 2 == 0 }          // [2, 4]
listOf(1, 2, 3, 4).filterNot { it % 2 == 0 }          // [1, 3]
listOf(1, "hello", 2.0).filterIsInstance<String>()    // ["hello"]
listOf("a", null, "b").filterNotNull()                // ["a", "b"]
val (passed, failed) = numbers.partition { it >= 5 }  // split into two

val nested = listOf(listOf(1, 2), listOf(3, 4))
nested.flatten()                                      // [1, 2, 3, 4]
users.flatMap { it.roles }                            // flatten + map

// Chaining
users.filter { it.active }.map { it.name }.sorted().joinToString(", ")
```

## Aggregations

```kotlin
val numbers = listOf(1, 2, 3, 4, 5)

numbers.reduce { acc, n -> acc + n }       // 15 (first element as seed)
numbers.fold(0) { acc, n -> acc + n }      // 15 (you provide seed)
numbers.fold(1) { acc, n -> acc * n }      // 120

numbers.sum()
numbers.average()
numbers.count()
numbers.minOrNull()
numbers.maxOrNull()

items.sumOf { it.price * it.quantity }     // projection sum

// groupBy returns Map<K, List<V>>
users.groupBy { it.dept }
users.groupBy(keySelector = { it.dept }, valueTransform = { it.name })
users.groupingBy { it.dept }.eachCount()

// associate — inverse of map
users.associateBy { it.name }              // Map<String, User>
listOf("a", "bb").associateWith { it.length }  // {a=1, bb=2}

// zip
listOf("a", "b").zip(listOf(1, 2))         // [(a,1), (b,2)]
listOf("a", "b").zip(listOf(1, 2)) { k, v -> "$k=$v" }
```

## Sequences (lazy evaluation)

Chaining `.map().filter().take()` on a list creates intermediate lists. Sequences process one element at a time.

```kotlin
// EAGER: 3 intermediate lists
(1..1_000_000).toList().map { it * 2 }.filter { it % 3 == 0 }.take(10)

// LAZY: stops when take(10) is satisfied
(1..1_000_000).asSequence()
    .map { it * 2 }
    .filter { it % 3 == 0 }
    .take(10)
    .toList()   // terminal operation — now it executes
```

| Use `List` (eager) | Use `Sequence` (lazy) |
|---|---|
| Small (< 10K elements) | Large (> 10K) |
| 1-2 operations | 3+ operations |
| Need random access | Only iterate once |

```kotlin
listOf(1, 2, 3).asSequence()
sequenceOf(1, 2, 3)
generateSequence(1) { it + 1 }.take(10).toList()     // infinite, take 10

generateSequence(0 to 1) { (a, b) -> b to (a + b) }   // Fibonacci
    .map { it.first }.take(10).toList()

val primes = sequence {
    yield(2)
    var n = 3
    while (true) {
        if ((2 until n).none { n % it == 0 }) yield(n)
        n += 2
    }
}
```

Terminal operations trigger evaluation: `toList()`, `toSet()`, `first()`, `count()`, `sum()`, `forEach { }`, `any { }`.

## Scope functions: let, run, with, apply, also

| Function | Object ref | Return value | Use case |
|---|---|---|---|
| `let` | `it` | Lambda result | Null checks, transform, scoping |
| `run` | `this` | Lambda result | Configure + compute |
| `with` | `this` | Lambda result | Group calls on an object |
| `apply` | `this` | The object | Object configuration (builder) |
| `also` | `it` | The object | Side effects (logging, validation) |

```kotlin
// let — null-safe transform
name?.let { println("Found: $it"); sendEmail(it) }
"Hello".let { it.uppercase() }.let { it.take(5) }

// run — configure + compute
val greeting = "World".run { "Hello, ${this.uppercase()}!" }

// with — group calls
val description = with(user) { "Name: $name, Age: $age" }

// apply — builder
val user = User().apply {
    name = "Alice"
    age = 30
}

// also — side effects mid-chain
val numbers = mutableListOf(1, 2, 3)
    .also { println("Initial: $it") }
    .map { it * 2 }
    .also { println("After map: $it") }
```

```text
Transform/map a value?       → let
Null-safe operations?        → let (with ?.)
Configure + return result?   → run
Group calls on an object?    → with
Build/configure an object?   → apply
Side effects in a chain?     → also
```

## Destructuring

```kotlin
val (name, age) = Pair("Alice", 30)
val (x, y, z) = Triple(1.0, 2.0, 3.0)

val user = User("Alice", 30, "a@b.com")
val (name, age, email) = user          // data class, positional
val (_, userAge, _) = user             // skip with _

for ((key, value) in map) { }
users.forEach { (name, age, _) -> }
for ((index, name) in names.withIndex()) { }
```

Destructuring is positional (not name-based like TS). Only `data class`, `Pair`, `Triple`, and classes with `componentN()` operators. No spread/rest.

```kotlin
class Color(val hex: String) {
    operator fun component1(): Int = hex.substring(1, 3).toInt(16)
    operator fun component2(): Int = hex.substring(3, 5).toInt(16)
    operator fun component3(): Int = hex.substring(5, 7).toInt(16)
}
val (r, g, b) = Color("#FF8800")
```

## Inline functions

`inline` copies the function + lambda body to the call site — zero lambda allocation overhead. Stdlib functions like `map`, `filter`, `let` are all `inline`. Don't add `inline` yourself unless writing performance-critical higher-order functions.

## Practical patterns

```kotlin
// Data pipeline
fun processLogs(entries: List<LogEntry>): Map<String, List<String>> =
    entries
        .filter { it.level == "ERROR" }
        .groupBy { it.service }
        .mapValues { (_, logs) -> logs.map { "${it.timestamp}: ${it.message}" }.sorted() }
        .filterValues { it.isNotEmpty() }

// Null-safe processing chain
fun getOrderSummary(orderId: String): String =
    findOrder(orderId)
        ?.let { order ->
            val customerName = order.customer?.name ?: "Guest"
            val total = order.items.sumOf { it.price * it.quantity }
            val discount = order.customer?.tier?.let {
                when (it) { "gold" -> 0.10; "silver" -> 0.05; else -> 0.0 }
            } ?: 0.0
            "Order ${order.id}: $customerName, total $${"%.2f".format(total * (1 - discount))}"
        }
        ?: "Order $orderId not found"

// Collection to lookup map
val productById: Map<String, Product> = products.associateBy { it.id }
val priceByName: Map<String, Double> = products.associate { it.name to it.price }
val byPriceRange = products.groupBy {
    when { it.price < 5.0 -> "budget"; it.price < 20.0 -> "mid"; else -> "premium" }
}
```
