You write TypeScript or Go backends. This course maps what you know onto Kotlin/JVM — every concept shown TS-style, Go-style, and Kotlin-style, with runnable examples.

## Setup

Install **JDK 21**, **Docker**, and an IDE (IntelliJ IDEA or VS Code + Kotlin plugin). Module 01 covers this in detail. Short version:

<Steps>

1. Start all infrastructure (PostgreSQL, Redis, Kafka):

   ```bash
   cd shared-infra && docker compose up -d
   ```

2. Verify services are running:

   ```bash
   docker compose ps
   ```

3. Tear everything down when done:

   ```bash
   docker compose down -v
   ```

</Steps>

| Tool | Version |
|------|---------|
| JDK | 21 (LTS) |
| Kotlin | 2.x |
| Gradle | 8.x (Kotlin DSL) |
| Spring Boot | 3.x |

## How each module works

Each module is a lesson plus hands-on exercises. Every exercise is a self-contained Gradle project:

<FileTree>
- module-name/
  - lesson content + side-by-side code examples
  - exercises/
    - project-name/
      - build.gradle.kts
      - settings.gradle.kts
      - docker-compose.yml if needed
      - src/
</FileTree>

```bash
./gradlew build
./gradlew run
```

Tear down module Docker services with `docker compose down -v`.
