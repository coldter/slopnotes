## Goal

Build a config loader that reads from a **pluggable source** (a dict or the process environment) and returns a fully typed `AppConfig` — nested dataclasses, `Literal`/`StrEnum` fields. On bad input it collects *every* problem into a structured error list instead of throwing on the first one, and reports them with an exhaustive `match`.

Constraint: **stdlib + `typing` only** — no Pydantic (module 04). Everything here is `dataclasses`, `Protocol`, `Literal`, `Enum`, PEP 695 generics, and `match`.

## Requirements

<Steps>

1. Define a `ConfigSource` Protocol with one method, `get(key) -> str | None`. Provide `DictSource` (wraps a dict) and `EnvSource` (reads `os.environ`). The loader depends only on the Protocol.

2. Model the config as a dataclass tree: `ServerConfig`, `DatabaseConfig`, and a top-level `AppConfig` holding both plus a `StrEnum` log level.

3. Parse with a generic `require` helper that takes a `str -> T | None` parser and accumulates the right error (missing vs invalid).

4. Return a typed `Result` — `Ok(config)` or `Err(errors)` — and dispatch with an exhaustive `match`; each error variant displays via `match` + `assert_never`, so adding a variant is a checker error.

</Steps>

### The source Protocol — pluggable, structural

Neither `DictSource` nor `EnvSource` declares it implements `ConfigSource`; they just have the right shape, and `ty` verifies it at the use site.

```python title="src/config_parser/__init__.py"
import os
from dataclasses import dataclass
from enum import StrEnum
from typing import Protocol, assert_never


class ConfigSource(Protocol):
    def get(self, key: str) -> str | None: ...


class DictSource:
    """Reads from an in-memory dict — does NOT inherit ConfigSource."""

    def __init__(self, data: dict[str, str]) -> None:
        self._data = data

    def get(self, key: str) -> str | None:
        return self._data.get(key)


class EnvSource:
    """Reads from the process environment."""

    def get(self, key: str) -> str | None:
        return os.environ.get(key)
```

    port: int


@dataclass(frozen=True)
class DatabaseConfig:
    url: str

    name: str
    debug: bool
    log_level: LogLevel
    server: ServerConfig
    database: DatabaseConfig

### The error model and result type

`ConfigError` is a closed union (base + frozen subclasses) — the sealed/discriminated type idiom. `Result[T] = Ok[T] | Err`; `Err` holds no value, so it fits any `Result[T]`.

```python title="src/config_parser/__init__.py"
from typing import Never

@dataclass(frozen=True)
class MissingKey:
    key: str


@dataclass(frozen=True)
class InvalidValue:
    key: str
    value: str
    expected: str


type ConfigError = MissingKey | InvalidValue


@dataclass(frozen=True)
class Ok[T]:
    value: T


@dataclass(frozen=True)
class Err:
    errors: list[ConfigError]


type Result[T] = Ok[T] | Err
```

### Generic parsing helpers

Each parser turns a raw string into `T | None`. `require` is the reusable generic core: give it a key and a parser, and it appends the right error (missing vs invalid) or returns the parsed `T`.

```python title="src/config_parser/__init__.py"
from collections.abc import Callable

def parse_str(raw: str) -> str | None:
    return raw


def parse_int(raw: str) -> int | None:
    try:
        return int(raw)
    except ValueError:
        return None


def parse_bool(raw: str) -> bool | None:
    match raw.strip().lower():
        case "true" | "1" | "yes":
            return True
        case "false" | "0" | "no":
            return False
        case _:
            return None


def parse_log_level(raw: str) -> LogLevel | None:
    try:
        return LogLevel(raw.strip().lower())
    except ValueError:
        return None


def require[T](
    source: ConfigSource,
    key: str,
    parse: Callable[[str], T | None],
    expected: str,
    errors: list[ConfigError],
) -> T | None:
    raw = source.get(key)
    if raw is None:
        errors.append(MissingKey(key))
        return None
    parsed = parse(raw)
    if parsed is None:
        errors.append(InvalidValue(key, raw, expected))
        return None
    return parsed
```

### Loading the config

```python title="src/config_parser/__init__.py"
def load_config(source: ConfigSource) -> Result[AppConfig]:
    errors: list[ConfigError] = []

    host = require(source, "SERVER_HOST", parse_str, "string", errors)
    port = require(source, "SERVER_PORT", parse_int, "integer", errors)
    db_url = require(source, "DATABASE_URL", parse_str, "string", errors)
    pool = require(source, "DATABASE_POOL_SIZE", parse_int, "integer", errors)
    name = require(source, "APP_NAME", parse_str, "string", errors)
    debug = require(source, "APP_DEBUG", parse_bool, "bool (true/false)", errors)
    level = require(source, "LOG_LEVEL", parse_log_level, "log level", errors)

    if errors:
        return Err(errors)

    # Past the guard, every value is non-None. assert narrows the type for ty.
    assert host is not None and port is not None
    assert db_url is not None and pool is not None
    assert name is not None and debug is not None and level is not None

    return Ok(
        AppConfig(
            name=name,
            debug=debug,
            log_level=level,
            server=ServerConfig(host=host, port=port),
            database=DatabaseConfig(url=db_url, pool_size=pool),
        )
    )
```

`assert x is not None` is the idiomatic narrowing for the checker — it also fails loudly at runtime if your logic is ever wrong.

### Displaying errors with an exhaustive match

```python title="src/config_parser/__init__.py"
def describe_error(error: ConfigError) -> str:
    match error:
        case MissingKey(key=key):
            return f"missing required key: {key}"
        case InvalidValue(key=key, value=value, expected=expected):
            return f"invalid value for {key!r}: {value!r} (expected {expected})"
        case _:
            assert_never(error)   # add a variant to ConfigError -> ty errors here
```

### main — dispatch the result

```python title="src/config_parser/__init__.py"
def main() -> None:
    # One good, one bad (non-int port, unknown log level), one missing (APP_NAME).
    raw = {
        "SERVER_HOST": "0.0.0.0",
        "SERVER_PORT": "not-a-number",
        "DATABASE_URL": "postgresql://dev:dev@localhost:5432/app",
        "DATABASE_POOL_SIZE": "10",
        "APP_DEBUG": "true",
        "LOG_LEVEL": "verbose",
    }
    source: ConfigSource = DictSource(raw)

    match load_config(source):
        case Ok(value=config):
            print("loaded config:")
            print(f"  {config}")
        case Err(errors=errors):
            print(f"config invalid ({len(errors)} problem(s)):")
            for err in errors:
                print(f"  - {describe_error(err)}")


if __name__ == "__main__":
    main()
```

Swap `DictSource(raw)` for `EnvSource()` and the same `load_config` reads your real environment — the Protocol paying off.

## Run it

<Steps>

1. Scaffold the project:

   ```bash
   uv init --package config-parser
   cd config-parser
   ```

2. Drop the solution into `src/config_parser/__init__.py` and run it — `uv` creates the venv on first run, no activate step:

   ```bash
   uv run config-parser
   ```

   Expected — all three errors reported, not just the first:

   ```text
   config invalid (3 problem(s)):
     - invalid value for 'SERVER_PORT': 'not-a-number' (expected integer)
     - missing required key: APP_NAME
     - invalid value for 'LOG_LEVEL': 'verbose' (expected log level)
   ```

3. Typecheck — the real point of the exercise:

   ```bash
   uv run ty check
   ```

   It should pass clean. Prove the safety net: delete the `case InvalidValue(...)` branch in `describe_error`, run `uv run ty check` again — `ty` flags the `assert_never` because the union is no longer fully handled.

</Steps>

:::tip[Stretch goals]
- **Retire the asserts.** Build each sub-config as its own `Result[ServerConfig]` / `Result[DatabaseConfig]` and combine them — the success path then has no `None`s to narrow.
- **Prefixed source.** Write a `PrefixedSource` wrapping another `ConfigSource` that prepends `"MYAPP_"` to every key — structurally a `ConfigSource` for free, no inheritance.
- **Range validation.** Add an `OutOfRange` variant to `ConfigError` (port must be 1–65535). Watch `ty` flag every `match` that doesn't handle it — that's exhaustiveness doing your refactoring TODO list.
- **Layered config.** Take a `list[ConfigSource]` and resolve each key from the first source that has it (env overrides file overrides defaults).
:::
