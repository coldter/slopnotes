You write TypeScript or Go backends. This course maps what you already know onto modern Python: `uv` replaces pip/virtualenv/poetry, `ruff` replaces black+flake8+isort, `ty` is the fast type checker, and `async` is a first-class way to build services. Legacy tools get named once, then dropped.

Every module is a runnable `uv` project shown three ways — TypeScript, Go, Python.

## Setup

You need **Python 3.13+** (we target 3.14), **uv**, and **Docker**.

<Steps>

1. Install uv — it manages Python itself, no separate install needed:

   ```bash
   curl -LsSf https://astral.sh/uv/install.sh | sh
   uv python install 3.14
   ```

2. Start all infrastructure (PostgreSQL, Redis, Kafka):

   ```bash
   cd shared-infra && docker compose up -d
   ```

3. Tear everything down when done:

   ```bash
   docker compose down -v
   ```

</Steps>

## How each module works

Each module is a lesson plus hands-on exercises. Every exercise is a self-contained `uv` project with a worked solution:

<FileTree>
- module-name/
  - the lesson content + side-by-side code examples
  - exercises/
    - project-name/
      - pyproject.toml
      - docker-compose.yml if the exercise needs infrastructure
      - src/
</FileTree>

Building and running any exercise is the same uv dance:

```bash
uv sync                    # create the venv and install deps (like npm install)
uv run python -m app.main  # run it (uv handles the venv for you)
uv run pytest              # run tests
```

Tear down module-specific Docker services with `docker compose down -v`.

## Shared infrastructure

| Service | Port | Credentials |
|---------|------|-------------|
| PostgreSQL | 5432 | `dev` / `dev` / `app` |

```bash
cd shared-infra && docker compose up -d   # start everything
docker compose down -v                     # stop and wipe all data
```
