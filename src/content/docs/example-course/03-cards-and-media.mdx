import { Card, CardGrid, LinkCard, Badge, FileTree } from '@astrojs/starlight/components';

These components add structured, scannable layout to a page. They are only
available in `.mdx` files.

## Card grids

Use `<CardGrid>` to lay out a set of `<Card>` components in a responsive grid.
Each card takes a `title` and an optional `icon` (from Starlight's built-in icon set):

<CardGrid>
  <Card title="Write" icon="pencil">
    Draft lessons as markdown files inside a course folder.
  </Card>
  <Card title="Preview" icon="laptop">
    Run the dev server to see pages render with the slop-learn theme.
  </Card>
  <Card title="Register" icon="setting">
    Add the course to the sidebar config so it shows up in navigation.
  </Card>
  <Card title="Ship" icon="rocket">
    Commit and push — the static site rebuilds with the new course.
  </Card>
</CardGrid>

## Link cards

`<LinkCard>` is for prominent, single navigation targets:

<LinkCard
  title="Authoring Guide"
  description="How slop-learn is organized and how to add your own course."
  href="/authoring/"
/>

<LinkCard
  title="Add a Course"
  description="Step-by-step instructions for creating and registering a new course."
  href="/authoring/add-a-course/"
/>

## Badges

`<Badge>` renders a small inline label, useful for status: <Badge text="Stable" variant="success" />,
<Badge text="Draft" variant="caution" />, or <Badge text="Deprecated" variant="danger" />.
Badges also support a `size` prop: <Badge text="New" variant="tip" size="large" />.

## File trees

`<FileTree>` documents directory layouts. Mark the current/highlighted entry with
`**bold**`, and annotate entries with trailing text:

<FileTree>

- src
  - content
    - docs
      - example-course
        - **overview.md** the page you started on
        - 01-text-and-callouts.md
        - 02-code-and-tabs.mdx
        - 03-cards-and-media.mdx
      - authoring/
  - config
    - sidebar.json registers each course group

</FileTree>
