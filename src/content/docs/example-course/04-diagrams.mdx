import Mermaid from "~/components/Mermaid.astro";

slopnotes renders [Mermaid](https://mermaid.js.org/) diagrams with a custom
`<Mermaid>` component. Every diagram is **interactive**: scroll to zoom toward
the cursor, drag to pan, double-click to zoom in, pinch on touch, and use the
toolbar to fit the view or go fullscreen. Diagrams also re-theme automatically
when you toggle light/dark mode.

## Using it

Import the component in any `.mdx` file and pass the diagram source as `code`:

````mdx
import Mermaid from "~/components/Mermaid.astro";

<Mermaid title="My diagram" code={`
flowchart LR
  A --> B --> C
`} />
````

`title` is optional (it labels the toolbar). The `height` prop (default `440`)
sets the viewport height in pixels.

## Flowcharts

Flowcharts are the workhorse. This one is large on purpose — pan and zoom to
read it, or open it fullscreen:

<Mermaid title="Authoring & publishing lifecycle" height={500} code={`

  subgraph Pipeline["Build pipeline"]
    Build --> Pages["Static pages"]

  end
  Pages --> Ship(["Publish"])
  Search --> Ship
`} />

## Sequence diagrams

Great for showing how parts of a system talk over time:

<Mermaid title="How a diagram reaches the reader" code={`
sequenceDiagram
  autonumber
  participant R as Reader
  participant B as Browser
  participant M as mermaid.js
  R->>B: Open a lesson
  B->>B: Render static HTML
  B->>M: Hand over the diagram source
  M-->>B: Return an SVG
  B->>R: Show the interactive diagram
  R->>B: Scroll, zoom, fullscreen
`} />

## State diagrams

## Git graphs

Branch and merge history, rendered with the site accent:

<Mermaid title="Adding a course" height={320} code={`
gitGraph
  commit id: "init"
  branch course
  checkout course
  commit id: "lesson"
  commit id: "diagram"
  checkout main
  merge course
  commit id: "publish"
`} />

:::tip
For very dense diagrams, click the **fit** button (the frame icon) to recenter,
then zoom into the part you care about — or go **fullscreen** for the most room.
:::
