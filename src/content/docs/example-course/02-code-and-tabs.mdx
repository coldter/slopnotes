Starlight renders code with [Expressive Code](https://expressive-code.com/), which
adds titles, line highlighting, and diff markers on top of plain fenced blocks.

## Titles and line highlighting

Add a `title=` to label the block as a file or terminal, and a `{n}` range to
highlight specific lines:

```js title="src/config/sidebar.json" {1,3-4}
export const sidebar = [
  { label: 'Overview', slug: 'example-course/overview' },
  { label: 'Text & Callouts', slug: 'example-course/01-text-and-callouts' },
  { label: 'Code & Tabs', slug: 'example-course/02-code-and-tabs' },
];
```

Lines 1 and 3–4 are highlighted above.

## Diff markers

Use `ins`/`del` markers in the meta string to render added and removed lines
without a real diff hunk:

```js title="astro.config.mjs" ins={3} del={2}
export default defineConfig({
  output: 'static',
  output: 'server',
});
```

You can also annotate individual lines inline with Expressive Code's comment
markers:

```js
const ok = true; // [!code highlight]
const noop = () => {};
```

## Tabbed examples

`<Tabs>` is ideal for "pick your package manager" style content. Use `syncKey`
so all tab groups on the page switch together:

<Tabs syncKey="pkg">
  <TabItem label="npm">

```sh
npm install @astrojs/starlight
```

  </TabItem>
  <TabItem label="pnpm">

```sh
pnpm add @astrojs/starlight
```

  </TabItem>
  <TabItem label="yarn">

```sh
yarn add @astrojs/starlight
```

  </TabItem>
</Tabs>

## Steps

Wrap an ordered list in `<Steps>` to render it as a vertical, numbered procedure:

<Steps>

1. Create the course folder under `src/content/docs/`.

2. Add a markdown file with `title` and `description` frontmatter.

3. Register the course in `src/config/sidebar.json`.

4. Run the dev server and confirm the page appears in the sidebar.

</Steps>
