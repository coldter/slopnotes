Effect is a **runtime for TypeScript programs**: errors, dependencies, resources, concurrency, and observability are *values in your type system*, not conventions. If you've wanted `Promise` to carry its error type, DI checked at compile time, or real cancellation — v4 is that runtime.

```ts
interface Effect<out A, out E = never, out R = never>
```

- `A` — success type
- `E` — typed failure channel (`Promise` has none — the headline feature)
- `R` — required services (context)

Because an Effect is inert data, the runtime can interrupt fibers, retry with backoff, manage resources under interruption, memoize dependencies, and propagate spans — things a promise can't do.

## Promise vs Effect

| Property | `Promise<A>` | `Effect<A, E, R>` |
|---|---|---|
| When created | starts immediately | inert |
| Failure type | `any` | `E`, tracked in the type |
| Requirements | none expressible | `R` — services from context |
| Cancellation | impossible | fiber interruption + cleanup |
| Re-runnable | no — memoized | yes — re-execute the description |
| Sync support | no | `Effect.runSync` |
| Composition | methods + `await` | combinators + generator syntax |

## What changed in v4

| Theme | v3 | v4 |
|---|---|---|
| Packages | `effect` + many `@effect/*` | Consolidated into `effect`; `effect/unstable/*` paths for http/httpapi/sql/ai |
| Versioning | independent per package | one version for the ecosystem |
| Services | `Context.Tag`, `Effect.Service`, … | one primitive: `Context.Service` (+ `Context.Reference`) |
| Fiber-local state | `FiberRef` | removed — `Context.Reference` |
| Runtime | `Runtime<R>` + `RuntimeFlags` | deleted — `Context<R>` *is* the runtime |
| Errors | `catchAll`, `catchSome` | `catch`, `catchFilter`, `Filter` module, reason-errors |
| Cause | recursive tree | flat `{ reasons: Reason[] }` |
| Yieldable types | `Ref`/`Fiber`/`Deferred`/`Queue` were Effects | only `Effect`, `Option`, `Result`, `Config`, `Context.Key` |
| Equality | reference, `Data` for structure | structural by default |
| Either | `Either<L, R>` | `Result<E, A>`, error-first |
| STM | `STM`, `TRef`, `TQueue` | `TxRef`, `TxQueue`, `TxHashMap` |
| Keep-alive | needed `runMain` | reference-counted keep-alive in core |

A minimal program tree-shakes to ~6 KB gzipped (~15 KB with Schema) — the `Micro` runtime was deleted.

:::note[Status]
Tracks `effect@4.0.0-rc.*`. `effect/unstable/*` modules may break in minor releases; everything else follows semver.
:::

## Setup

```sh
pnpm add effect@latest            # v4 line
pnpm add @effect/platform-node    # NodeRuntime.runMain, HTTP server, file system
```

Enable `strict`, and ideally `exactOptionalPropertyTypes: true` — several Schema optionality variants only distinguish under it.
