Auther runs sign-up, sign-in, password hashes, 2FA, session tokens, and key rotation. Your app receives a signed JWT and trusts it — no per-service login code.

It also answers *what a user can do*: a hybrid **ReBAC + ABAC** engine inspired by Google Zanzibar. Permissions are computed from relationship tuples and embedded in the JWT, so the common-case check is zero-latency. Only context-dependent decisions fall back to a live lookup.
