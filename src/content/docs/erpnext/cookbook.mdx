The **Frappe Developer Cookbook** is the companion to the [Guide](/erpnext/overview/):
56 self-contained recipes, each roughly 80% code and 20% explanation. Every recipe
follows the same shape so you can scan it fast:

- **Problem** — what you're trying to solve.
- **Solution** — complete, runnable code with file paths.
- **Why this works** — the mechanism in a sentence or two.
- **Common mistake** — the pitfall to avoid.

Every recipe uses the **ScoopJoy** franchise theme, and they're self-contained —
jump straight to whichever one matches your current need.
