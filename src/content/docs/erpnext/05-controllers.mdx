Each DocType's controller is a Python class extending `frappe.model.document.Document`, wired by naming convention — the Express equivalent of route handler + model hooks in one file.

The class name is the DocType name in PascalCase: `Franchise Outlet` → `FranchiseOutlet`, `Sales Invoice` → `SalesInvoice`.

```python title="scoopjoy/scoopjoy/franchise_management/doctype/franchise_outlet/franchise_outlet.py"
import frappe
from frappe.model.document import Document


class FranchiseOutlet(Document):

    def validate(self):
        """Runs before every save. Throw errors here to prevent saving."""
        self.validate_city_code()
        self.validate_rent()

    def validate_city_code(self):
        if self.city_code and len(self.city_code) != 3:
            frappe.throw("City Code must be exactly 3 characters")

    def validate_rent(self):
        if self.monthly_rent and self.monthly_rent < 0:
            frappe.throw("Monthly Rent cannot be negative")
```

## Lifecycle hooks — execution order

In Express you chain middleware explicitly; in Frappe the lifecycle is fixed — opt in by defining the named method. Wrong placement = logic that runs too late (e.g. validation in `on_update` can't block a save).

<Mermaid title="Insert lifecycle" height={520} code={`
stateDiagram-v2
  [*] --> autoname
  autoname --> before_naming
  before_naming --> before_validate: name is set
  before_validate --> validate
  validate --> before_insert
  before_insert --> INSERT: INSERT INTO database
  INSERT --> after_insert
  after_insert --> on_update
  on_update --> on_change
  on_change --> [*]
`} />

On a plain **save** of an existing document, naming is skipped and `before_save` replaces the insert-only hooks:

<Mermaid title="Save lifecycle" height={420} code={`
stateDiagram-v2
  [*] --> before_validate
  before_validate --> validate
  validate --> before_save: compute derived values
  before_save --> UPDATE: UPDATE in database
  UPDATE --> on_update
  on_update --> on_change
  on_change --> [*]
`} />

For **submittable** DocTypes, submit/cancel add hooks around the `docstatus` transition:

<Mermaid title="Submit and cancel lifecycle" height={460} code={`
stateDiagram-v2
  Draft --> Submitted: submit()
  Submitted --> Cancelled: cancel()

  state Submitted {
    [*] --> before_submit
    before_submit --> on_submit: docstatus = 1, UPDATE
    on_submit --> done_submit
  }

  state Cancelled {
    [*] --> before_cancel
    before_cancel --> on_cancel: docstatus = 2, UPDATE
    on_cancel --> done_cancel
  }
`} />

Delete lifecycle:

```text title="Delete lifecycle"
on_trash()     # before deletion — cleanup linked data
               # ↓ DELETE FROM database
after_delete() # post-deletion cleanup
```

Use `before_submit` for final preconditions, `on_submit` to create GL/stock entries, `on_cancel` to reverse them, `on_trash` to block deletion of linked records.

## The `self` object

Inside any hook, `self` is the Document instance:

```python title="franchise_outlet.py"
class FranchiseOutlet(Document):
    def validate(self):
        self.outlet_name        # "Scoops & Shakes - Andheri"
        self.name               # "FO-MUM-0001" (set after autoname)
        self.monthly_rent       # 85000.0

        for item in self.equipment:      # child rows = list of Document objects
            item.equipment_name          # "Gelato Display Freezer"
            item.idx                     # row number (1-based)
            item.parent                  # "FO-MUM-0001"
            item.parenttype              # "Franchise Outlet"
            item.parentfield             # "equipment"

        self.meta.is_submittable                  # 0
        self.meta.get_field("status").options     # "\nActive\nInactive\n..."
        self.is_new()                             # True on first insert

        if self.has_value_changed("status"):
            frappe.msgprint(f"Status changed to {self.status}")

        if self.flags.ignore_validate:            # runtime-only, not persisted
            return
```

## Validation: `frappe.throw()` vs `frappe.msgprint()`

```python title="franchise_outlet.py"
def validate(self):
    # frappe.throw() — raises, prevents save, shows red error
    if not self.manager:
        frappe.throw(
            msg="Outlet Manager is required for all franchise outlets",
            title="Missing Manager",
            exc=frappe.ValidationError,  # optional, defaults to ValidationError
        )

    # frappe.msgprint() — shows a message, save proceeds
    if not self.pincode:
        frappe.msgprint(
            msg="Consider adding a pincode for better logistics tracking",
            title="Suggestion",
            indicator="orange",  # blue, green, orange, red
        )
```

| Call | Stops save? | Use for |
|---|---|---|
| `frappe.throw()` | Yes | Invalid data that must block the save |
| `frappe.msgprint()` | No | Suggestions, warnings, informational alerts |

## Full controller example

```python title="franchise_outlet.py"
import frappe
from frappe import _
from frappe.model.document import Document


class FranchiseOutlet(Document):

    def autoname(self):
        """Custom naming: FO-{CITY_CODE}-{serial}. Overrides the JSON autoname."""
        if not self.city_code:
            frappe.throw(_("City Code is required for naming"))
        self.city_code = self.city_code.upper().strip()

    def validate(self):
        self.validate_city_code()
        self.validate_opening_date()
        self.validate_equipment()
        self.calculate_total_equipment_cost()

    def validate_city_code(self):
        if len(self.city_code) != 3:
            frappe.throw(
                _("City Code must be exactly 3 characters. Got: {0}").format(self.city_code)
            )

    def validate_opening_date(self):
        if self.opening_date and self.status == "Active":
            from frappe.utils import getdate, today
            if getdate(self.opening_date) > getdate(today()):
                frappe.msgprint(
                    _("Opening date is in the future. Status will remain as-is."),
                    indicator="orange",
                )

    def validate_equipment(self):
        seen = set()
        for row in self.equipment:
            if row.equipment_name in seen:
                frappe.throw(
                    _("Row {0}: Duplicate equipment '{1}'. Merge rows and update quantity instead.").format(
                        row.idx, row.equipment_name
                    )
                )
            seen.add(row.equipment_name)
            if row.quantity < 1:
                frappe.throw(_("Row {0}: Quantity must be at least 1").format(row.idx))

    def calculate_total_equipment_cost(self):
        self.total_equipment_cost = sum(
            (row.purchase_cost or 0) * (row.quantity or 1)
            for row in self.equipment
        )

    def after_insert(self):
        """Create a default warehouse for the new outlet."""
        if not self.default_warehouse:
            warehouse = create_outlet_warehouse(self)
            # db.set_value to avoid re-triggering hooks
            frappe.db.set_value(
                "Franchise Outlet", self.name, "default_warehouse", warehouse.name
            )

    def on_update(self):
        """Called after every save (insert or update)."""
        if self.has_value_changed("manager"):
            frappe.msgprint(
                _("Outlet manager changed to {0}").format(self.manager_name),
                alert=True,
            )

    def on_trash(self):
        """Prevent deletion of active outlets."""
        if self.status == "Active":
            frappe.throw(_("Cannot delete an Active outlet. Set status to Closed first."))


def create_outlet_warehouse(outlet):
    """Create a Warehouse for a new Franchise Outlet."""
    warehouse = frappe.new_doc("Warehouse")
    warehouse.warehouse_name = f"{outlet.outlet_name} - Store"
    warehouse.company = frappe.defaults.get_defaults().get("company")
    warehouse.parent_warehouse = "Stores - SJ"
    warehouse.franchise_outlet = outlet.name
    warehouse.insert(ignore_permissions=True)
    frappe.msgprint(
        _("Warehouse '{0}' created for this outlet.").format(warehouse.name),
        alert=True,
    )
    return warehouse
```

## Whitelisted methods — HTTP APIs

`@frappe.whitelist()` exposes a Python function at `/api/method/<dotted.path>`. The dotted module path **is** the URL — no router to maintain.

```python title="franchise_outlet.py"
@frappe.whitelist()
def calculate_royalty(outlet_name, month, year):
    """POST /api/method/scoopjoy.franchise_management.doctype.franchise_outlet.franchise_outlet.calculate_royalty"""
    outlet = frappe.get_doc("Franchise Outlet", outlet_name)

    total_sales = frappe.db.sql("""
        SELECT IFNULL(SUM(grand_total), 0) as total
        FROM `tabSales Invoice`
        WHERE franchise_outlet = %s
          AND MONTH(posting_date) = %s
          AND YEAR(posting_date) = %s
          AND docstatus = 1
    """, (outlet_name, month, year), as_dict=True)[0].total

    # Royalty tiers (Indian franchise model)
    if total_sales <= 500000:        # up to 5 lakh
        royalty_rate = 0.05
    elif total_sales <= 1500000:     # 5-15 lakh
        royalty_rate = 0.07
    else:                            # above 15 lakh
        royalty_rate = 0.10

    return {
        "outlet_name": outlet.outlet_name,
        "month": month,
        "year": year,
        "total_sales": total_sales,
        "royalty_rate": royalty_rate * 100,
        "royalty_amount": total_sales * royalty_rate,
    }
```

Call from client JS with `frappe.call`:

```javascript title="franchise_outlet.js"
frappe.call({
    method: 'scoopjoy.franchise_management.doctype.franchise_outlet.franchise_outlet.calculate_royalty',

        year: frappe.datetime.str_to_obj(frappe.datetime.now_date()).getFullYear(),

        if (r.message) {
            frappe.msgprint(
                `Royalty for ${r.message.outlet_name}: ₹${r.message.royalty_amount.toLocaleString('en-IN')}`
            );
        }
    }
});
```

### Whitelisted methods on the document class

Whitelist a method on the controller class; `frm.call` passes the doc name automatically:

```python title="franchise_outlet.py"
class FranchiseOutlet(Document):

    @frappe.whitelist()
    def get_equipment_summary(self):
        summary = {}
        for row in self.equipment:
            category = row.equipment_type or "Other"
            summary.setdefault(category, {"count": 0, "cost": 0})
            summary[category]["count"] += row.quantity
            summary[category]["cost"] += (row.purchase_cost or 0) * row.quantity
        return summary
```

```javascript title="franchise_outlet.js"
frm.call('get_equipment_summary').then(r => {
    console.log(r.message);
});
```

v16: state-changing whitelisted methods only accept POST (GET still works for read-only methods).

## Background jobs with `frappe.enqueue()`

Offload long work to RQ workers — the BullMQ equivalent. Never block the web request.

```python title="franchise_outlet.py"
@frappe.whitelist()
def bulk_update_compliance_status():
    """Enqueue a background compliance check for all outlets."""
    frappe.enqueue(
        method="scoopjoy.franchise_management.doctype.franchise_outlet.franchise_outlet._run_compliance_check",
        queue="long",                # short (5min), default (5min), long (25min)
        timeout=1200,                # 20 minutes max
        job_name="Franchise Compliance Check",
        enqueue_after_commit=True,   # wait until current transaction commits
    )
    frappe.msgprint(
        "Compliance check started in the background. You will be notified when complete.",
        alert=True,
    )


def _run_compliance_check():
    """Background job. Runs in a worker process. NOT whitelisted — not an API endpoint."""
    outlets = frappe.get_all(
        "Franchise Outlet",
        filters={"status": "Active"},
        fields=["name", "outlet_name"],
    )

    failed = []
    for outlet in outlets:
        try:
            is_compliant = check_outlet_compliance(outlet.name)
            frappe.db.set_value(
                "Franchise Outlet", outlet.name,
                "compliance_status",
                "Compliant" if is_compliant else "Non-Compliant",
            )
        except Exception:
            failed.append(outlet.outlet_name)
            frappe.log_error(title=f"Compliance check failed: {outlet.name}")

    frappe.db.commit()  # background jobs do NOT auto-commit

    frappe.publish_realtime(
        event="msgprint",
        message=f"Compliance check complete. {len(outlets) - len(failed)} passed, {len(failed)} failed.",
        user=frappe.session.user,
    )


def check_outlet_compliance(outlet_name):
    """Check if outlet has valid FSSAI, GST, and trade license."""
    licenses = frappe.get_all(
        "Outlet License",
        filters={"outlet": outlet_name, "status": "Valid"},
        fields=["license_type"],
    )
    required = {"FSSAI", "GST", "Trade License"}
    held = {lic.license_type for lic in licenses}
    return required.issubset(held)
```

### Queue types and timeouts

| Queue | Default timeout | Use case |
|---|---|---|
| `short` | 300s (5 min) | One email, a few record updates |
| `default` | 300s (5 min) | Standard background work |
| `long` | 1500s (25 min) | Bulk updates, report generation, data import |

:::caution
`frappe.enqueue` fails when 500 jobs are already queued (`MAX_QUEUED_JOBS`). Design background jobs to be idempotent — they may retry on failure.
:::

## Database operations in controllers

`frappe.db` is the low-level layer for when you don't need a full document load and its hooks. (Full ORM: `get_doc`, `get_all`, filter operators, raw SQL — see [DocTypes](/erpnext/04-doctypes/).)

```python title="franchise_outlet.py"
frappe.db.exists("Franchise Outlet", "FO-MUM-0001")
frappe.db.exists("Franchise Outlet", {"outlet_name": "Scoops & Shakes - Andheri"})

rent = frappe.db.get_value("Franchise Outlet", "FO-MUM-0001", "monthly_rent")

vals = frappe.db.get_value(
    "Franchise Outlet", "FO-MUM-0001",
    ["outlet_name", "monthly_rent", "status"],
    as_dict=True,
)

frappe.db.set_value("Franchise Outlet", "FO-MUM-0001", "status", "Closed")  # bypasses hooks

count = frappe.db.count("Franchise Outlet", {"status": "Active", "city": "Mumbai"})

results = frappe.db.sql(
    "SELECT city, COUNT(*) as cnt FROM `tabFranchise Outlet` WHERE status=%s GROUP BY city",
    ("Active",),
    as_dict=True,
)
```

### When to call `frappe.db.commit()`

| Context | Commit? |
|---|---|
| Controller hooks (`validate`, `on_update`, …) | **No** — Frappe auto-commits at end of request |
| Background jobs | **Yes** — workers do not auto-commit |
| Whitelisted API methods | Usually no; commit only for mid-function durability between batches |

:::caution
Calling `frappe.db.commit()` inside a controller hook can leave inconsistent state if the save fails later — committed changes can't roll back. Only commit in background jobs or when you explicitly need mid-transaction durability.
:::

## `run_method()` and `Document.flags`

`run_method()` invokes a hook by name and also fires any `doc_events` other apps registered for it:

```python
outlet = frappe.get_doc("Franchise Outlet", "FO-MUM-0001")
outlet.run_method("validate")  # runs validate + hooks.py doc_events for "validate"
```

Flags are runtime-only, not persisted — pass context between hooks or skip logic during bulk import:

```python title="franchise_outlet.py"
class FranchiseOutlet(Document):
    def validate(self):
        if not self.flags.skip_rent_validation:
            self.validate_rent()

    def validate_rent(self):
        if self.monthly_rent and self.monthly_rent < 10000:
            frappe.throw("Monthly rent seems too low. Verify the amount.")


doc = frappe.get_doc("Franchise Outlet", "FO-MUM-0001")
doc.flags.skip_rent_validation = True
doc.monthly_rent = 5000  # normally fails validation
doc.save()
```

| Flag | Purpose |
|---|---|
| `flags.ignore_permissions` | Skip permission checks on save/submit/cancel |
| `flags.ignore_validate` | Skip the validate hook entirely |
| `flags.ignore_mandatory` | Skip mandatory field checks |
| `flags.ignore_links` | Skip Link field validation |
| `flags.in_migrate` | Set during `bench migrate` |

## Error handling and logging

Wrap secondary work in `try/except` and log to the `Error Log` DocType instead of crashing the primary operation:

```python title="franchise_outlet.py"
def after_insert(self):
    try:
        warehouse = create_outlet_warehouse(self)
        frappe.db.set_value(
            "Franchise Outlet", self.name, "default_warehouse", warehouse.name
        )
    except Exception:
        frappe.log_error(title=f"Failed to create warehouse for {self.name}")
        # Don't re-raise — the outlet was created; warehouse is secondary.
        frappe.msgprint(
            "Outlet created but warehouse could not be auto-created. "
            "Please create one manually.",
            indicator="orange",
        )
```

View errors at **Desk > Error Log** or `GET /api/resource/Error Log`. Old entries are auto-cleaned by a scheduled job.

## Extending standard DocTypes (v16)

v16's `extend_doctype_class` hook lets multiple apps safely extend the same DocType (the older `override_doctype_class` allows only one app — last-writer-wins). `super()` chains correctly through all extensions.

```python title="scoopjoy/hooks.py"
extend_doctype_class = {
    "Sales Invoice": "scoopjoy.overrides.sales_invoice.CustomSalesInvoice",
}
```

```python title="scoopjoy/overrides/sales_invoice.py"
import frappe
from frappe import _


class CustomSalesInvoice:
    """Mixin: methods here are added to the SalesInvoice class."""

    def validate(self):
        super().validate()  # original first
        self.validate_franchise_outlet()

    def validate_franchise_outlet(self):
        if self.franchise_outlet and not frappe.db.exists("Franchise Outlet", self.franchise_outlet):
            frappe.throw(_("Franchise Outlet {0} does not exist").format(self.franchise_outlet))
```

### Alternative: `doc_events` in hooks.py

Simpler cases — hook a standard DocType's lifecycle without extending its class. Closest to Express middleware: a function `(doc, method)` on a named event.

```python title="scoopjoy/hooks.py"
doc_events = {
    "Sales Invoice": {
        "validate": "scoopjoy.overrides.sales_invoice_hooks.validate_franchise_fields",
        "on_submit": "scoopjoy.overrides.sales_invoice_hooks.create_franchise_royalty_entry",
    },
    "Customer": {
        "after_insert": "scoopjoy.overrides.customer_hooks.link_to_franchise_outlet",
    },
    "*": {  # wildcard — runs for ALL DocTypes
        "on_update": "scoopjoy.overrides.common.log_all_changes",
    },
}
```

```python title="scoopjoy/overrides/sales_invoice_hooks.py"
import frappe
from frappe import _


def validate_franchise_fields(doc, method):
    """`doc` is the Document instance, `method` is the hook name ("validate")."""
    if doc.franchise_outlet:
        outlet = frappe.get_doc("Franchise Outlet", doc.franchise_outlet)
        if outlet.status != "Active":
            frappe.throw(
                _("Cannot create invoice for inactive outlet: {0}").format(outlet.outlet_name)
            )


def create_franchise_royalty_entry(doc, method):
    """On submit, create a royalty accrual entry."""
    if not doc.franchise_outlet:
        return
    royalty_rate = get_royalty_rate(doc.franchise_outlet)
    if royalty_rate:
        je = frappe.new_doc("Journal Entry")
        je.posting_date = doc.posting_date
        je.franchise_outlet = doc.franchise_outlet
        je.append("accounts", {
            "account": "Franchise Royalty Income - SJ",
            "credit_in_account_currency": doc.grand_total * royalty_rate,
        })
        je.append("accounts", {
            "account": "Franchise Royalty Receivable - SJ",
            "debit_in_account_currency": doc.grand_total * royalty_rate,
        })
        je.insert(ignore_permissions=True)
        je.submit()
```

## Where to put your logic

| Need | Hook / Method | Notes |
|---|---|---|
| Set the document name | `autoname()` | Runs only on first insert |
| Validate data before save | `validate()` | `frappe.throw()` blocks the save |
| Compute derived values | `before_save()` | Fields that depend on other fields |
| Create linked documents after insert | `after_insert()` | Warehouse, default settings |
| React to any save | `on_update()` | Notifications, cache invalidation |
| Lock data on submission | `before_submit()` | Final checks before locking |
| Create accounting/stock entries | `on_submit()` | GL entries, stock ledger entries |
| Reverse entries on cancel | `on_cancel()` | Undo what `on_submit` did |
| Cleanup before deletion | `on_trash()` | Block deletion of linked records |
| Expose an API endpoint | `@frappe.whitelist()` | Module-level or class method |
| Run heavy work in background | `frappe.enqueue()` | Bulk ops, reports |
| Extend a standard DocType | `extend_doctype_class` (v16) | Safe multi-app extension via hooks.py |
| Hook standard DocType events | `doc_events` | Simpler than class extension |
