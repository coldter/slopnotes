Every receipt, issue, transfer, or manufacture creates a **Stock Ledger Entry (SLE)** — an append-only valuation ledger. The **Bin** DocType holds the current snapshot per item-warehouse combination.

## Warehouse hierarchy

Warehouses form a tree: **group** warehouses are containers, **leaf** warehouses hold stock. ScoopJoy separates the central kitchen (production) from outlets (selling):

<FileTree>
- ScoopJoy Ice Creams Pvt Ltd Company, implicit root
  - All Warehouses - SJ (Group)
    - Central Kitchen - SJ (Group)
      - Raw Materials Store - SJ
      - WIP - SJ
      - Finished Goods - SJ
    - Outlet 1 - SJ (Group)
      - Outlet 1 Display Freezer - SJ
      - Outlet 1 Cold Storage - SJ
    - Outlet 2 - SJ (Group)
      - Outlet 2 Display Freezer - SJ
      - Outlet 2 Cold Storage - SJ
    - Outlet 3 - SJ (Group)
      - Outlet 3 Display Freezer - SJ
      - Outlet 3 Cold Storage - SJ
    - Scrap Warehouse - SJ
</FileTree>

Build it in the Desk Tree View (**Stock > Warehouse**) or programmatically — group first, then leaves:

```python title="scoopjoy/scoopjoy/setup/warehouses.py"
# Create a group warehouse
group_wh = frappe.get_doc({
    "doctype": "Warehouse",
    "warehouse_name": "Central Kitchen",
    "is_group": 1,
    "parent_warehouse": "All Warehouses - SJ",
    "company": "ScoopJoy Ice Creams Pvt Ltd"
})
group_wh.insert()

# Create child warehouses
for name in ["Raw Materials Store", "WIP", "Finished Goods"]:
    wh = frappe.get_doc({
        "doctype": "Warehouse",
        "warehouse_name": name,
        "is_group": 0,
        "parent_warehouse": "Central Kitchen - SJ",
        "company": "ScoopJoy Ice Creams Pvt Ltd"
    })
    wh.insert()
```

With Perpetual Inventory enabled, each warehouse links to a **Stock In Hand** GL account — assign different accounts per warehouse if needed (e.g. separate finished-goods valuation from raw materials).

|---|---|
| `item_code` / `item_name` | Unique ID / display name |

## Batch tracking

Essential for food: trace every batch from production to sale, track expiry, pick FEFO. Batches auto-create on stock transactions when `create_new_batch` is set on the item, or create manually (`batch_qty` is auto-calculated from SLEs — never set it):

```python title="scoopjoy/scoopjoy/stock/batch.py"
batch = frappe.get_doc({
    "doctype": "Batch",
    "batch_id": "VANMIX-20250715-B01",
    "item": "SCOOP-VAN-REG",
    "manufacturing_date": "2025-07-15",
    "expiry_date": "2025-10-13",     # 90-day shelf life
    "reference_doctype": "Stock Entry",
    "reference_name": "STE-2025-00142"
})
batch.insert()
```

On-hand qty of one batch in one warehouse:

```python title="scoopjoy/scoopjoy/stock/batch.py"
from erpnext.stock.doctype.batch.batch import get_batch_qty

batch_qty = get_batch_qty(
    batch_no="VANMIX-20250715-B01",
    warehouse="Outlet 1 Display Freezer - SJ",
    item_code="SCOOP-VAN-REG"
)
print(f"Batch qty: {batch_qty}")
```

**Stock > Batch-Wise Balance History** shows qty per batch per warehouse with expiry and age. Automated expiry sweep:

```python title="scoopjoy/scoopjoy/stock/expiry.py"
from frappe.utils import today, add_days

expiring_batches = frappe.get_all("Batch",
    filters={
        "expiry_date": ["between", [today(), add_days(today(), 7)]],
        "batch_qty": [">", 0]
    },
    fields=["batch_id", "item", "expiry_date", "batch_qty"],
    order_by="expiry_date asc"
)
for b in expiring_batches:
    print(f"EXPIRING: {b.batch_id} ({b.item}) - Expires {b.expiry_date} - Qty: {b.batch_qty}")
```

Set a **Notification** rule (Settings > Notification) to email daily about batches expiring within 7 days — critical for waste and food safety.

## Valuation: FIFO vs Moving Average

| Method | How it works | Best for |
|---|---|---|
| **FIFO** | Oldest stock valued first; each layer keeps its own rate | Perishables, food (matches physical flow) |
| **Moving Average** | Single weighted-average rate updated on each receipt | Commodities, stable-price items |

Same 80-litre issue, different COGS:

<Tabs>
  <TabItem label="FIFO">

  ```text
  Receipt 1: 100 litres @ INR 200/L  -> Stock: 100 @ 200
  Receipt 2:  50 litres @ INR 220/L  -> Stock: 100 @ 200 + 50 @ 220
  Issue:      80 litres              -> Issued: 80 @ 200 (oldest first)
                                      -> Remaining: 20 @ 200 + 50 @ 220
  COGS for the issue = 80 x 200 = INR 16,000
  ```

  </TabItem>
  <TabItem label="Moving Average">

  ```text
  Receipt 1: 100 litres @ INR 200/L  -> Avg rate: 200
  Receipt 2:  50 litres @ INR 220/L  -> Avg rate: (100x200 + 50x220) / 150 = 206.67
  Issue:      80 litres              -> Issued: 80 @ 206.67
  COGS for the issue = 80 x 206.67 = INR 16,533.60
  ```

  </TabItem>
</Tabs>

Set per item in the Item master, or a default at **Stock Settings > Default Valuation Method**. For food, FIFO almost always wins — it matches sell-oldest-first and gives accurate COGS when ingredient prices move.

### Bin fields

```python title="scoopjoy/scoopjoy/stock/inspect.py"
bin_data = frappe.get_value("Bin",
    {"item_code": "SCOOP-VAN-REG", "warehouse": "Outlet 1 Display Freezer - SJ"},
```

| Bin field | Meaning |
|---|---|
| `actual_qty` | Physical stock in warehouse |
| `planned_qty` | Qty planned for production (Work Orders) |
| `reserved_qty` | Reserved for Sales Orders |
| `ordered_qty` | Ordered via POs, not yet received |
| `projected_qty` | `actual - reserved + ordered + planned` — available to promise |

## Real-time stock API for dashboards

Whitelisted function reading Bin snapshots, enriched with earliest batch expiry:

```python title="scoopjoy/scoopjoy/api.py"
import frappe

@frappe.whitelist()
def get_outlet_stock_summary(warehouse=None):
    filters = {"actual_qty": [">", 0]}
    if warehouse:
        filters["warehouse"] = warehouse

    bins = frappe.get_all("Bin",
        filters=filters,
        fields=[
            "item_code", "warehouse", "actual_qty",
            "reserved_qty", "projected_qty",
            "valuation_rate", "stock_value"
        ],
        order_by="item_code"
    )

    for b in bins:
        batches = frappe.get_all("Stock Ledger Entry",
            filters={
                "item_code": b.item_code,
                "warehouse": b.warehouse,
                "actual_qty": [">", 0]
            },
            fields=["batch_no"],
            distinct=True
        )
        batch_nos = [x.batch_no for x in batches if x.batch_no]
        if batch_nos:
            b["earliest_expiry"] = frappe.db.get_value("Batch",
                {"batch_id": ["in", batch_nos]},
                "min(expiry_date)"
            )

    return bins
```

Client side:

```javascript title="scoopjoy/scoopjoy/public/js/stock_dashboard.js"

    method: "scoopjoy.api.get_outlet_stock_summary",
    args: { warehouse: "Outlet 1 Display Freezer - SJ" },

            r.message.forEach(function(item) {
                console.log(item.item_code, "Qty:", item.actual_qty,

});
```
