ERPNext v16+ runs on the **Frappe Framework**. Each chapter maps a Frappe concept to the Node.js/Express equivalent you already know — a whitelisted Python method is a route handler, a DocType is a schema + controller + REST API in one.

Everything is themed around **ScoopJoy**, a franchise ice-cream chain in India: multiple outlets, a central kitchen, 50+ staff, POS at every counter, GST accounting, and a React/Node storefront calling ERPNext's REST API.

## Who this is for

- Backend developers (Node.js assumed; any backend transfers).
- You know SQL, Redis, Docker, HTTP APIs.
- Little or no Frappe/Python-framework experience.

## The stack

| Component | Version | Role |
|-----------|---------|------|
| Frappe / ERPNext | v16+ | The framework + the ERP app |
| Python | 3.14+ | Server logic, ORM, controllers, API |
| Node.js | 24 LTS | Asset bundling, Socket.IO realtime server |
| MariaDB | 10.6+ | Primary database (Postgres 14+ also supported) |
| Redis | 8+ | Cache, job queues, real-time pub/sub |
| Nginx + Gunicorn | latest | Reverse proxy + WSGI app server (production) |
| `bench` | latest | The Frappe CLI for sites, apps, and ops |
