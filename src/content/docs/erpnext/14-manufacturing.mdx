## Bill of Materials (BOM)

A BOM is the recipe: raw materials, sub-assemblies, quantities, and operations — plus costing and a submit lifecycle. From Node.js: it's a `recipes` table plus a join table for ingredients, with operations and costing built in.

### Create a BOM

Two child tables: `items` (materials) and `operations` (steps). Set `with_operations = 1` to cost labour and machine time alongside materials:

```python title="scoopjoy/scoopjoy/manufacturing/bom_setup.py"
def create_vanilla_ice_cream_bom():
    """BOM for Vanilla Ice Cream 500ml."""
    bom = frappe.new_doc("BOM")
    bom.item = "ICE-VAN-500"
    bom.item_name = "Vanilla Ice Cream 500ml"
    bom.quantity = 1
    bom.company = "ScoopJoy Ice Creams Pvt Ltd"
    bom.is_active = 1
    bom.is_default = 1
    bom.with_operations = 1

    materials = [
        ("RM-MILK-WHOLE", "Whole Milk", 0.3, "Litre", 40),
        ("RM-SUGAR-WHITE", "White Sugar", 0.05, "Kg", 45),
        ("RM-VANILLA-EXTRACT", "Vanilla Extract", 0.005, "Litre", 800),
        ("RM-CREAM", "Cream", 0.15, "Litre", 120),
        ("RM-STABILIZER", "Stabilizer", 0.002, "Kg", 500),
        ("PKG-TUB-500", "Ice Cream Tub 500ml", 1, "Nos", 3.50),
        ("PKG-LID-500", "Tub Lid 500ml", 1, "Nos", 1.20),
        ("PKG-LABEL-VAN", "Vanilla Label", 1, "Nos", 0.80),
    ]

    for code, name, qty, uom, rate in materials:
        bom.append("items", {
            "item_code": code,
            "item_name": name,
            "qty": qty,
            "uom": uom,
            "rate": rate,
            "source_warehouse": "Central Warehouse - SJ"
        })

    # Operations
    bom.append("operations", {"operation": "Mixing", "workstation": "Mixing Station", "time_in_mins": 15, "operating_cost": 5})
    bom.append("operations", {"operation": "Pasteurization", "workstation": "Pasteurizer", "time_in_mins": 30, "operating_cost": 10})
    bom.append("operations", {"operation": "Freezing", "workstation": "Batch Freezer", "time_in_mins": 45, "operating_cost": 15})
    bom.append("operations", {"operation": "Packaging", "workstation": "Packaging Line", "time_in_mins": 5, "operating_cost": 3})

    bom.insert()
    bom.submit()
    return bom.name
```

### BOM cost

Material cost = Σ `qty × rate`; operating cost = Σ `operating_cost`; total = both. For the BOM above:

| Component | Qty | UOM | Rate (INR) | Amount |
|---|---|---|---|---|
| Whole Milk | 0.3 | Litre | 40 | 12.00 |
| White Sugar | 0.05 | Kg | 45 | 2.25 |
| Vanilla Extract | 0.005 | Litre | 800 | 4.00 |
| Cream | 0.15 | Litre | 120 | 18.00 |
| Stabilizer | 0.002 | Kg | 500 | 1.00 |
| Tub 500ml | 1 | Nos | 3.50 | 3.50 |
| Lid 500ml | 1 | Nos | 1.20 | 1.20 |
| Label | 1 | Nos | 0.80 | 0.80 |
| **Material Cost** | | | | **42.75** |
| Mixing (15 min) | | | | 5.00 |
| Pasteurization (30 min) | | | | 10.00 |
| Freezing (45 min) | | | | 15.00 |
| Packaging (5 min) | | | | 3.00 |
| **Operating Cost** | | | | **33.00** |
| **Total BOM Cost** | | | | **75.75** |

Use the BOM's **Update Cost** button to recalculate from the latest stock-ledger valuation rates when ingredient prices move.

## Work Order

The instruction to the shop floor. Lifecycle is driven by Stock Entries against it:

<Mermaid title="Work Order lifecycle: Draft → NotStarted → InProcess (Job Cards) → Completed" height={520} code={`
stateDiagram-v2
  [*] --> Draft
  Draft --> NotStarted: submit
  NotStarted --> InProcess: Stock Entry<br/>(Material Transfer for Manufacture)
  InProcess --> InProcess: Job Cards completed<br/>(one per operation)
  InProcess --> Completed: Stock Entry (Manufacture)<br/>finished goods received
  Completed --> [*]
`} />

Material Transfer moves raw materials stores → WIP; Manufacture consumes WIP and receives finished goods → FG.

```python title="scoopjoy/scoopjoy/manufacturing/work_order.py"
def create_work_order_vanilla(qty=100):
    """Work Order for 100 units of Vanilla Ice Cream."""
    wo = frappe.new_doc("Work Order")
    wo.production_item = "ICE-VAN-500"
    wo.bom_no = "BOM-ICE-VAN-500-001"
    wo.qty = qty
    wo.company = "ScoopJoy Ice Creams Pvt Ltd"
    wo.wip_warehouse = "Work In Progress - SJ"
    wo.fg_warehouse = "Finished Goods - SJ"
    wo.source_warehouse = "Central Warehouse - SJ"
    wo.use_multi_level_bom = 1
    wo.skip_transfer = 0  # require the material-transfer step (clean WIP hand-off)
    wo.planned_start_date = frappe.utils.now()

    wo.insert()
    wo.submit()
    return wo.name
```

`make_stock_entry` builds a pre-populated Stock Entry from the Work Order — no hand-assembled material rows:

```python title="scoopjoy/scoopjoy/manufacturing/work_order.py"
from erpnext.manufacturing.doctype.work_order.work_order import make_stock_entry

# Start production: transfer raw materials stores → WIP
se_transfer = make_stock_entry(work_order_id="WO-00042", purpose="Material Transfer for Manufacture", qty=100)
se_transfer.insert()
se_transfer.submit()

# Finish production: consume WIP, receive finished goods → FG
se_manufacture = make_stock_entry(work_order_id="WO-00042", purpose="Manufacture", qty=100)
se_manufacture.insert()
se_manufacture.submit()
# 100 units of ICE-VAN-500 now in Finished Goods - SJ; raw materials consumed from WIP
```

## Production Plan & MRP

The Production Plan is the MRP engine: aggregates demand from Sales Orders and Material Requests, nets it against stock, explodes BOMs, and fans out into Work Orders + Material Requests.

<Mermaid title="Open Sales Orders + Material Requests → Production Plan → Work Orders + Material Requests" height={360} code={`
flowchart LR
  SO["Open Sales Orders"] --> PP["Production Plan<br/>(MRP)"]
  MR0["Material Requests"] --> PP
  PP -->|"make_work_order"| WO["Work Orders<br/>(finished goods + sub-assemblies)"]
  PP -->|"make_material_request"| MR["Material Requests<br/>(raw materials to purchase)"]
`} />

v16 MRP improvements: Master Production Schedule views, better lead-time consideration, phantom BOM support, stock reservation for specific jobs.

```python title="scoopjoy/scoopjoy/manufacturing/production_plan.py"
def create_weekly_production_plan():
    """Weekly production plan across all products for all outlets."""
    pp = frappe.new_doc("Production Plan")
    pp.company = "ScoopJoy Ice Creams Pvt Ltd"
    pp.posting_date = frappe.utils.today()
    pp.get_items_from = "Sales Order"

    pp.run_method("get_open_sales_orders")  # pull planned items from open SOs

    # Or add manually
    pp.append("po_items", {
        "item_code": "ICE-VAN-500",
        "bom_no": "BOM-ICE-VAN-500-001",
        "planned_qty": 500,
        "warehouse": "Finished Goods - SJ",
        "planned_start_date": frappe.utils.today()
    })
    pp.append("po_items", {
        "item_code": "ICE-CHOC-500",
        "bom_no": "BOM-ICE-CHOC-500-001",
        "planned_qty": 400,
        "warehouse": "Finished Goods - SJ",
        "planned_start_date": frappe.utils.today()
    })
    pp.append("po_items", {
        "item_code": "ICE-MAN-500",
        "bom_no": "BOM-ICE-MAN-500-001",
        "planned_qty": 300,
        "warehouse": "Finished Goods - SJ",
        "planned_start_date": frappe.utils.today()
    })

    pp.insert()
    pp.submit()

    pp.run_method("make_work_order")          # generate Work Orders
    pp.run_method("make_material_request")    # generate Material Requests for raw materials

    return pp.name
```

MRP math per planned item:

```text
Required Qty = Planned Qty − Available Qty (warehouse)
  (if "Skip Available Sub-Assembly Items": subtract available sub-assemblies too)
Raw materials (BOM explosion):
  Required Qty = (Planned Qty × BOM qty per unit) − Projected Qty
Material Requests generated for raw materials to buy + sub-assemblies to manufacture
```

## Job Card & Workstation

Each BOM operation gets a Job Card tracking time, materials, and operator:

```python title="scoopjoy/scoopjoy/manufacturing/job_card.py"
job_card = frappe.get_doc("Job Card", "JC-00101")  # auto-created on Work Order submit
job_card.append("time_logs", {
    "from_time": frappe.utils.now(),
    "completed_qty": 0,
    "employee": "HR-EMP-0005"
})
job_card.save()

job_card.time_logs[0].to_time = frappe.utils.now()
job_card.time_logs[0].completed_qty = 100
job_card.save()
job_card.submit()
```

Workstations are physical equipment with capacity; per-hour rates (`hour_rate_electricity + hour_rate_labour + hour_rate_consumable`) feed operation operating cost:

```python title="scoopjoy/scoopjoy/manufacturing/workstation_setup.py"
def setup_workstations():
    workstations = [
        {"name": "Mixing Station", "production_capacity": 200,  # litres/hour
         "hour_rate_electricity": 15, "hour_rate_labour": 50, "hour_rate_consumable": 5,
         "working_hours": [{"start_time": "06:00:00", "end_time": "14:00:00"},
                           {"start_time": "14:00:00", "end_time": "22:00:00"}]},
        {"name": "Batch Freezer", "production_capacity": 100,   # litres/hour
         "hour_rate_electricity": 40, "hour_rate_labour": 50, "hour_rate_consumable": 10,
         "working_hours": [{"start_time": "00:00:00", "end_time": "23:59:59"}]},  # 24/7
        {"name": "Packaging Line", "production_capacity": 500, # units/hour
         "hour_rate_electricity": 10, "hour_rate_labour": 40, "hour_rate_consumable": 3,
         "working_hours": [{"start_time": "06:00:00", "end_time": "22:00:00"}]}
    ]

    for ws_data in workstations:
        ws = frappe.new_doc("Workstation")
        ws.workstation_name = ws_data["name"]
        ws.production_capacity = ws_data["production_capacity"]
        ws.hour_rate_electricity = ws_data["hour_rate_electricity"]
        ws.hour_rate_labour = ws_data["hour_rate_labour"]
        ws.hour_rate_consumable = ws_data["hour_rate_consumable"]
        for wh in ws_data["working_hours"]:
            ws.append("working_hours", wh)
        ws.insert()

    frappe.db.commit()
```

## Manufacturing Settings

| Setting | Recommended value | Purpose |
|---|---|---|
| Default WIP Warehouse | Work In Progress - SJ | Materials during production |
| Default FG Warehouse | Finished Goods - SJ | Finished products |
| Overproduction % for Work Order | 10 | Allow 10% overproduction |
| Capacity Planning For (Workstation) | Yes | Enable capacity checks |
| Disable Capacity Planning | No | Enforce workstation capacity |
| Allow Overtime | Yes | Schedule beyond working hours |

### Week-of-production planning

```python title="scoopjoy/scoopjoy/manufacturing/production_plan.py"
def weekly_production_plan():
    """Plan the coming week from open Sales Orders + current stock."""
    pp = frappe.new_doc("Production Plan")
    pp.company = "ScoopJoy Ice Creams Pvt Ltd"
    pp.posting_date = frappe.utils.today()
    pp.get_items_from = "Sales Order"
    pp.from_date = frappe.utils.today()
    pp.to_date = frappe.utils.add_days(frappe.utils.today(), 7)

    pp.run_method("get_open_sales_orders")

    for item in pp.po_items:
        print(f"{item.item_code}: Plan {item.planned_qty} units")
        # item.planned_qty = adjusted_qty  # adjust as needed

    pp.insert()
    pp.run_method("get_sub_assembly_items")  # multi-level BOM
    pp.submit()

    pp.run_method("make_work_order")
    pp.run_method("make_material_request")

    work_orders = frappe.get_all("Work Order", filters={
        "production_plan": pp.name
    }, fields=["name", "production_item", "qty"])
    for wo in work_orders:
        print(f"  WO {wo.name}: {wo.production_item} x {wo.qty}")

    return pp.name
```

### Tracking WIP and finished goods

```python title="scoopjoy/scoopjoy/manufacturing/status.py"
def get_production_status(work_order_name):
    """Work Order header + operation progress from Job Cards + WIP value from SLEs."""
    wo = frappe.get_doc("Work Order", work_order_name)

    print(f"Work Order: {wo.name}")
    print(f"Item: {wo.production_item}")
    print(f"Ordered Qty: {wo.qty}")
    print(f"Material Transferred: {wo.material_transferred_for_manufacturing}")
    print(f"Produced Qty: {wo.produced_qty}")
    print(f"Status: {wo.status}")

    job_cards = frappe.get_all("Job Card", filters={"work_order": wo.name},
        fields=["operation", "status", "total_completed_qty"])
    print("\nOperation Progress:")
    for jc in job_cards:
        progress = (jc.total_completed_qty / wo.qty) * 100
        print(f"  {jc.operation}: {jc.status} ({progress:.0f}%)")

    wip_value = frappe.db.sql("""
        SELECT SUM(stock_value_difference)
        FROM `tabStock Ledger Entry`
        WHERE voucher_no IN (
            SELECT name FROM `tabStock Entry`
            WHERE work_order = %s AND purpose = 'Material Transfer for Manufacture'
        )
        AND warehouse = %s
    """, (wo.name, wo.wip_warehouse))
    print(f"\nWIP Value: INR {wip_value[0][0] or 0:,.2f}")

    return {
        "status": wo.status,
        "ordered": wo.qty,
        "produced": wo.produced_qty,
        "remaining": wo.qty - wo.produced_qty
    }
```
